# Documentary plate layout transport

The current worker schema99 appends PreviewProtocolLayout/CaptureProtocolLayout/ExportProtocolLayout (182–184) and ProtocolLayoutPreview/Captured/Exported (172–174). Existing operation, candidate26/native-plan24 and science27 semantics do not change. Workspace inputs use the shared bounded128MiB lane; only the workspace-containing capture result needs that response lane. Layout preview/export retain native4MiB limits. No superseded internal reader is added.

The MCP `protocol_layout` tool accepts an immutable workspace reference and one typed task: Preview, Capture, List, Open, Export, ReviewPublication or ProjectPublication. Capture requires the exact preview context. Native capture returns a NEW immutable workspace, canonical documentary attachment and bounded receipt/native artifacts atomically; no original biological head or historical assessment changes. Export uses native CSV/HTML/PDF bytes and exposes warnings via immutable binary artifacts. There are190 current tools. Source event pins, construct/declaration hashes and recorded statuses remain explicit. Plate placement does not establish reagent amounts, samples, stock availability, kinetics, successful cloning or laboratory execution. Missing quantities are visible.

Ordinary selected-plasmid publication deliberately omits documentary layout and batch/release sidecars; the returned attachment-omission counts disclose that narrowing. Selecting one plasmid never silently publishes every other well. Complete plate projection is a separate explicit scope: `inspect_protocol_layout_closure` / `project_protocol_layout_closure` in library-sharing. Native `source_bindings` supplies the full exact dependency set. An indivisible batch/release record can refer to constructs beyond the assigned wells; its full typed dependencies must be retained, without silently stripping rows. Review counts/notices before approving this larger scope. The projection changes neither original workspace nor scientific identity.

MCP ReviewPublication returns the complete scope artifact and its digest; ProjectPublication requires that exact digest, recomputes scope, and returns the projected native archive in the session. It performs no server upload. The current browser plate editor need not expose publication controls yet; the explicit native/MCP path is usable without claiming that ordinary plasmid sharing includes complete plates. Unsupported SBOL or other source closures still fail closed.

New focused source fixtures are protocol_layout_transport (worker stateless/session context+capture+all exports), protocol_layout_tools (actual SDK native archive, stale capture refusal, exports and scope review), and protocol_layout_closure (ordinary omission, explicit dependency closure, untouched private document exclusion and missing-dependency refusal). No browser, HTTP, provider, compiler or application checks were run while preparing this patch; parent integration runs the shared native/WASM batch.
