# Current native-history construct QC

Current source passes selected native/WASM checks and the nine causal fixtures within the connected 2,934-case integration batch. [Combined compiler and execution evidence](causal-history-current-integration.json).
The public owner is `construct_qc::causal`, operating on one validated Workspace
and explicit source/product event and CDS-role declarations. It adds no executable
plan or biological/function certificate.

The request pins both EventBindings, both current AnnotationAssumptions, and the
exact genetic code. Unreviewed, stale or unavailable roles remain indeterminate.
An authored replacement CDS can be compared under its explicit role assumption
without pretending that native annotation identity survived the replacement.
Native feature correspondence is reported separately using original ordinals.

Current checked behavior includes native reference actions and donors, actual
cloning runs, saved material/run origins, native TOPO graph scopes and cached deep
origins, explicit Fork identity, reverse orientation, circular origins, and exact
joined coding paths. Missing/unretained analysis recipes remain indeterminate;
public context hashes do not supply missing replay authority. Native event/run
execution is cached across all requested pairs.

Register evidence follows actual reference calls. An annotation-only change of
CDS start/order cannot establish a DNA-junction cause. Actual joined reference
neighbors or an introduced block bounded by retained parent coding anchors can
establish a changed register. Segments retain later restoration after compensating
changes. Intron changes are excluded by the actual canonical biological path,
rather than by genomic distance or gene labels.

Stop comparisons use the existing CDS translator and exact table pin. A retained
intact parent stop is distinguished from a newly created stop. Changed/literal
codon calls use actual retained parent codon anchors. A downstream shifted stop
can be proven far from its initiating junction because the recorded register and
parent coding ordinals persist; no nearest-boundary heuristic or sequence
alignment supplies the relationship. Unsupported/ambiguous correspondence cannot
establish absence. No expression, function or experimental outcome is inferred.

Bounds are independent and explicit:

- At most 32 declared pairs; default 256 history events, 1 million coding calls,
  20 million receipt/coding comparison units, 512 total register segments and
  256 total stop evidence items.
- Hard request/report ceilings 128 KiB/2 MiB. Native source/annotation tree guards
  precede recursive hashing/copying. Full genomic/codon scans consume their
  declared coding or comparison budgets; exhausted no-stop scans do not pass.
- One shared native exact-PCR ledger (200 million actual units) and cleavage
  ledger (100 million actual units) cover QC replay and nested saved origins.
  Other native algorithms retain their own documented limits; `max_work` does
  not falsely advertise a global bound on every scientific method.
- Private trace construction, namespace depth, origin alternatives and source
  copies have their own monotonic shared bounds. An unrecordable native job is
  refused before more expensive replay; receipt refusal cannot change ordinary
  non-QC verification outcomes.

`Report::validate_binding` checks bounded documentary content/context.
`validate_request` also binds exact requested pair/CDS/code/limit fields without
running scientific reconstruction. `validate_for` deliberately performs fresh
scientific assessment and is for explicit imported evidence audit, not an
immediate second run after `assess`.
