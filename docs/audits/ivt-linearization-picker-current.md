# F40 restriction-linearization candidate foundation

2026-11-28: the scientific owner, binary worker, MCP tool and collapsed IVT
web controls are integrated. Native/WASM checks and the eight native, three SDK
and focused web-model fixtures pass in the connected batch. The web child shares
transcript, native-origin, generation and formulation controls. [Combined compiler and execution evidence](causal-history-current-integration.json).
GUI and real-provider acceptance remain deferred.

`Request` binds the existing IVT declaration, exact catalogue selection, explicit
source-input route, nullable reaction conditions, end/unknown-history policy and
shared comparison/output bounds. The IVT declaration must have no preselected
linearization; each candidate derives one separately. There is no winning-enzyme
field or sequence/material write.

`SourceInput::DeclaredOriginal` reuses the canonical one-step source-generation
operation and native verifier source guards. `Saved` uses the unchanged existing
`MaterialOrigin::replay` path directly, retaining its fresh tracked state rather
than reading state out of metadata. The source state hash includes positional
methylation/generation facts. This first scope requires a fully paired, intact
duplex reference without nicks or preexisting staggered ends; those unsupported
source geometries are refused explicitly. Original-generation declarations cannot
promote saved or imported physical/reference-only markers into fresh material.

Each selected enzyme is an alternative single-enzyme digestion, not a combined
cocktail. The existing positional checked-cleavage owner performs recognition,
methylation assessment and fragment construction. All cut outcomes, unknowns,
limits and fragment geometries survive into the report. Two permitted cuts never
gain unique-cut eligibility. A known blocked site can preserve an intact circular
survivor; unknown cleavage does not invent fragments. Missing sites are considered
absent only after that enzyme's complete determination.

The existing catalogue selection cap of 64 admits the complete current 40-enzyme
catalogue in one request. One comparison ledger spans all alternatives, up to
100 million comparisons. Limits also bound each enzyme to 64 retained sites,
the complete request to 8 MiB, and the report to at most 8 MiB. No result is silently
truncated to fit output bytes: aggregate admission fails before the next candidate
is retained. Recognition work, including unsuccessful searches, stays charged;
later budget-limited enzymes remain explicit unresolved alternatives. Hashing and
existing source/material validation have their separate bounded native costs.

Geometry projection maps actual top/bottom cut bonds into coding and template
offsets from +1. The exact signed stagger comes from the pinned enzyme geometry;
the observed cut-pair congruence is checked. For circular sources, only the coding
anchor is lifted into a turn, then the exact stagger produces the template cut.
Independently normalizing both cuts could hide a second turn or promoter cut and
is deliberately rejected. Both forward/reverse coding strands use their actual
source bonds. Fragment interval containment requires the complete upstream T7
promoter on both strands and the whole declared transcript on its template
strand, without copying or rescanning each residue per candidate.

A candidate requires complete determined cleavage with one permitted cut,
retained promoter/template interval, exact template runoff boundary and an allowed
end kind. Existing IVT assessment supplies the promoter, initiator, cap and runoff
checks; any established failure rejects eligibility. Unresolved checks, unknown
conditions and incomplete source history follow explicit caller policy and stay
visible. Exact user-selected formulation choices are assessed per alternative
with the existing documentary condition owner. Unknown ordinary/HF choices never
become implicit substitutions, and one alternative's unknown evidence does not
erase another's known record. Known documentary activity/temperature never implies
star/duration compatibility or actual cleavage completion.

`revision`, `assess`, `Report::validate_binding` and `validate_for` distinguish
bounded documentary integrity from fresh native recomputation. Reports bind the
original source revision, exact request, catalogue, current positional profile,
fresh material-state revision, candidate IVT request/report identities, conditions
and whole output revision. A candidate's derived IVT request is an explicitly
recorded cut hypothesis, not an executed cutting event or experimental result.

Eight authored fixtures cover literal blunt/staggered and forward/reverse bonds,
circular wraps and second-turn refusal, promoter disruption, wrong runoff,
multicuts, methylation unknown/blocked survivors, explicit ordinary/HF/unknown
conditions, full-catalogue admission, shared limits and aggregate-byte refusal,
stale/tampered evidence and a freshly replayed saved PCR source. Source facts and
cleavage algorithms remain owned by the existing catalogue, modified-duplex and
IVT modules. No new empirical enzyme or transcription parameter table is added.

Next scope gaps are integration, preexisting staggered/nicked source geometry,
mixed-enzyme candidates, partial-digest policies and physical isolation. Yield,
capping efficiency and end-homogeneity prediction are not introduced.
