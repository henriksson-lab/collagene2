# Positional checked Golden Gate

Golden Gate uses exact catalog identity and actual tracked strands through initial
cleavage, ordered fragment mapping, ligation and candidate recut assessment. The
same modification-aware digest kernel is used for preparative cuts. The target is
never an argument to native pool enumeration or private candidate construction.

`CheckedDigestOptions` contains a complete `CatalogSelection`, comparison bound
and site bound. The current profile identity is retained by the report and context;
there is no caller-supplied substitute profile. Catalog edition, canonical identity,
name and recognition/cut geometry must all match the embedded catalog before work.
Known unmodified eligible chemical positions can use exact nonstarter catalog cut
geometry without borrowing another enzyme's methylation sensitivity. Modified or
unknown positions require an exact applicable positional rule. Identical geometry,
isoschizomers and HF formulations do not substitute for identity-specific rules.

The current BsaI positional profile is explicitly R0535, including its unresolved
Dcm conflict. It is not BsaI-HFv2. Generic BsmBI does not silently acquire BsmBI-v2
rules. Source reports identify these limits. The current complete blocking rules
are full internal CpG at NotI/SmaI and overlapping full Dam at XbaI. This change
adds no invented blocking rule for the four Golden Gate enzymes.

Original DNA without a declared generation model remains chemically unknown.
Actual new PCR is unmodified under the synthesis model. Saved Run/Derived origins
must be freshly replayed; their generation records are not used as a shortcut for
chemical decisions. Decisions inspect actual positional states, including retained
bases whose original methylase motif no longer exists. Existing source limitations
and incomplete origin findings remain separate constraints in the verifier.

A blocked site survives. If every site is determined, native cut geometry yields
all surviving fragments; a blocked, uncut circle remains an intact circle. Unknown
or impaired cleavage withholds the entire requested source fragment pool, rather
than running the known subset as the complete reaction. All source evidence remains
available for review. This is a complete-cleavage model conditional on its stated
profiles and reaction assumptions, not a kinetic mixture simulation.

Every candidate is ligated from actual tracked fragments before recut assessment.
Junctions may create recognition sites containing inherited modified bases; their
outcomes are assessed on actual product strands, not newly scanned generation flags
or unmodified sequence copies. A private `FreshGoldenGate` retains a requested
candidate's actual tracked state from that same pass. Serialized reports cannot
restore it. Profile uncertainty does not change the candidate's literal sequence
or make its chemical state known unmodified.

`restriction_site_free` requires a complete scan with no recognition sites. A
blocked or unresolved surviving motif is never relabeled site-free. Recut sites
retain both geometry and a positional `Outcome`. Geometric accessibility alone
is insufficient for `cleavable_under_model`. Existing site-free candidate acceptance
remains conservative; no methylation-protected product is silently accepted as a
site-free cycling product. Neither retained alternatives nor a selected candidate
establish experimental isolation, probabilities, yields or kinetic stability.

`CleavageBudget` is one enclosing-plan ledger (at most 100 million recognition/context
comparisons) passed through that plan's preparative checks, Golden Gate source
checks and candidate recuts. Reports expose that enclosing ledger's used count.
Reconstructing a nested historical Run/Derived origin replays its own native
scope under a separate bounded ledger; this count does not include that work.
Shared native ancestry depth/byte/base/step limits still constrain those replays.
The reported count covers only the enclosing plan, rather than all transitive
replays. Proven site absence and actually unmodified recognition residues require
no irrelevant methylase-context scan; a budget that completes recognition exactly
can still prove those results. Exhaustion is explicit: source cutting
becomes undetermined and its requested pool is withheld; a candidate already
physically assembled remains available with incomplete recut classification and
no claimed motif absence. Search/product limits and the one-copy scope remain
separate. Source/fragment/candidate evidence is bounded to32MiB; inability to
represent that evidence is an explicit resource refusal, not silent omission.

Kernel fixtures independently specify a16-base circle from real unmodified PCR,
a Dcm-overlapping BsaI source withheld without generation-record shortcuts, a17-base
ligation that creates a methylation-uncertain BsaI junction, a same-sequence explicit
unmodified control, reverse-strand recut evidence, blocked intact NotI circles,
unequal7/3 AatII cut strands under an exact nonstarter identity, malformed pins,
and a shared preparation/source/recut budget. Existing permutation/origin/strand
geometry fixtures now state their unmodified generation assumptions explicitly.
