# Selected sharing of target-free saved-run digest fragments

A `saved-run-digest-fragment-v1` attachment is a typed native derivation record,
not an opaque private blob or proof reconstructed from a display label. The
shared-library graph indexes its canonical `run_digest_history::load_record`
product EventBinding and checks the exact event/document/revision. Multiple
records, or a record and a native run, cannot claim the same product event.

Only when that exact derived event enters the selected native closure does the
record enter the attachment inventory. The graph then follows the module's
`source_bindings` and `required_run_ids`, resolving the original source, each
nested capsule's declared source inputs, independent native run targets/products
and exact run declarations. Existing run companion/evidence handling remains.
The record's previous whole-workspace fingerprint is retained as documentary
source evidence; it does not cause unrelated current heads to be copied.

Choosing another document never queues this digest's origins or publishes its
record. Dependency documents are pinned to retained historical events, preserving
a later private local head in the original workspace rather than importing it
into publication. UI sidecars and standalone candidates remain excluded. Both
ordinary public and trusted native-private document projections use the same
native dependency traversal. Private/public SBOL evidence policies continue to
apply separately after native history scope is established.

The producer operation prefix `Target-free saved-run digest fragment ` is
reserved for detecting a missing native derivation. If its event is selected
without a typed owner, publication refuses. Text matching never establishes
ownership, finds substitute source events, selects a matching-DNA record or
permits opaque copying. Wrong bindings, media, duplicate owners, corrupt or
noncanonical records fail. Existing global workspace validation remains in force;
this adapter does not weaken it to rescue a partial archive.

Loading/sharing validates bounded documentary structure only. It does not promote
a stored duplex/record/report into current material authority or rewrite native
molecule/revision/event/capsule identities. `run_digest_history::reconstruct` or
its closed capsule replay must freshly evaluate the originating run and actual
catalog-pinned digest before material reuse. Independent target verification is
not invented for a target-free opened fragment. Historical producer science is
documentary; current replay policy belongs to the core module.

The `library-sharing` target `run_digest_closure` has three focused native fixture
groups. A real unique PCR produces a full original strand, then EcoRI fragment 0
is installed without a dummy target. Public and private closure archives reopen
and freshly reconstruct literal top `AGTCCGATGCTAG` and bottom
`AATTCTAGCATCGGACT`, preserving the original PCR outer terminus and new cleaved
terminus. The source's later private edited head, unrelated plasmid and UI state
are excluded while the original workspace stays unchanged. Additional cases
select an unrelated document (no record/origin leakage), remove the owner, corrupt
its canonical bytes and change its product binding. No browser, HTTP, external
program or live data is used. Formatting/scoped diff checks were run by the worker;
parent compiler/fixture validation remains pending.
