# Reusable mismatch PCR and direct saved-material repair

The Mutagenesis panel's collapsed **Open reusable mismatch-PCR material** review uses the applied actual primer pair and its explicit mismatch/3′ matching policy. The user selects an exact source event and, for saved material, a retained Run or Derived origin. Native worker previews reconstruct that origin before computing PCR; unsupported source geometry is reported without inserting a repair step. The ordinary intended mutation and inverse-PCR target remain separate.

The End repair panel offers **Repair selected saved material directly**. This requires a saved Run or Derived origin and an explicit repair method. Source preparation, restriction digestion, ligation, sealing, and activation are not inserted. The review displays actual source and resulting strand/end geometry, additions/removals, and inherited incomplete findings. The existing digest→repair and oligo-annealing workflows remain independent choices.

Both controls use the single `material_derivation` native installation transaction and its current/previous recovery storage. Full ordered primers can be saved atomically with a mismatch-PCR product. Installation recomputes fresh physics; preview capture and decoding do not commit anything or confer material authority. A single supported certain non-overlapping mismatch-PCR geometry can be reusable even when enumeration is incomplete, but all native limits remain explicit and no isolation or target-success claim is made. Multiple reported candidates do not enable an arbitrary isolated product.

Source document/event/revision, origin capsule, operation settings, output selection, name, and workspace epoch are checked before dispatch, reply use, installation, and native export-lane admission. Controls cancel outstanding workers when their source or policy changes. The UI shows bounded sequence/geometry excerpts and provides the complete context-guarded native preview JSON through the ordinary acknowledged export mechanism.
