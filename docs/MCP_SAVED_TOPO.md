# Saved native TOPO inspection through MCP

`inspect_saved_topo` is a read-only source-bound inspector. Its `inputs` are
immutable session `BoundInput` references, and `origin_workspace` names the exact
retained native archive. The required-nullable `template` is either `null` or
`{role, selection: MaterialSelection}`. Run and Derived selections are resolved
inside that workspace; closed capsules and supplied graph reports are not API
arguments. A graph-only continuation uses no invented PCR template or duplicate
insert inputs.

The externally tagged task is `Orientations`, `Project`, `Check`, `Simulate`, or
`ProcessActions`. Every preparation uses the same chronological `steps` array:
explicit source-call transfers, supported flap cleavage and selected nick sealing.
`Simulate` returns the complete native graph. `ProcessActions` uses the sole
`topo_actions` bridge request: `preparation`, canonical physical `selection` and
`options`. There is no independent processing or sealing phase request.

`Check.target` is a separate immutable session `DocumentRef`. It is resolved
without substituting projected graph DNA, choosing a productive orientation or
changing the desired target. Activation, primers, tails, actual call handles,
component/seed and acceptance allowances remain explicit. A reference contour is
not an ordinary material substrate.

The response retains `origin_incomplete` and bounded fresh originating findings,
with total and truncation fields. The native excerpt contains at most 128 findings
and 2,048 characters per finding; MCP adds no further truncation to this excerpt.
Saved graph history and local task limitations remain independently visible.
Local target agreement cannot clear inherited incompleteness. The full typed
`Inspection` and exact source/workspace/task evidence are retained in a bounded
artifact. No candidate, projected document or laboratory stock is installed by
this inspection tool.

Saved graph selections hydrate native records and source snapshots under the same
joint Run/Derived/graph ancestry ledger, before copying. Hydration is documentary;
one actual native execution supplies the graph. See [graph transport](TOPO_GRAPH_TRANSPORT.md)
and [saved templates](TOPO_SAVED_TEMPLATE.md) for ownership and material limits.

The SDK fixtures use actual finalized native products and imported archives, and
retain unrelated-archive, stale-source, wrong-role, missing-workspace and target
binding refusals. These checks establish the declared model and its exact source
identity, not isolation, empirical amplification or experimental success.
