# Target-free opening of a digest fragment from saved native material

`run_digest_history` provides the native core foundation for saved-run material → catalog-pinned digest → retained fragment. It does not manufacture an independent fragment target, claim target verification, add a dummy operation to satisfy the cloning-run recorder, or flatten saved material into an ordinary sequence input. Native archive validation and selected-document sharing are connected. Browser/worker/source-picker and typed downstream reconstruction remain separate required steps; this module alone does not close that user path.

## Recipe and installation

`Request` contains the exact source `EventBinding`, its existing closed native origin `Capsule`, a pinned `CatalogSelection`, bounded `InspectionOptions`, and the chosen zero-based fragment index. `preflight` checks the current active source head, immutable retained run/target/input/product ownership, current originating engine, catalog membership, model and ancestry bounds. Matching DNA from a different source or a fabricated but internally consistent origin recipe cannot attest installation.

`installation_revision` binds the original workspace fingerprint and exact request. `prepare_install` returns a fresh workspace plus receipt without mutating the caller. `install` encodes that result. The existing atomic history installation creates one derived document/event whose sole parent is the selected source event. The module adds a content-addressed `saved-run-digest-fragment-v1` attachment; it creates no new independent goal document, candidate or goal-checked cloning run.

Actual origin replay establishes the tracked original duplex. The normal bounded recognition/complete-cleavage model then digests those actual strands and positional modifications. Installation is withheld unless the actual product set is determined and the selected index exists. Source annotations are projected using the actual top cut coordinate and retained length. Top/bottom calls, stagger, terminal groups and modification state come from the existing native kernel, never a desired fragment sequence, imported duplex summary or cached report. Complete cleavage remains a declared virtual-digest assumption, not measured enzyme activity or a methylation-permission assessment. Existing unsupported nick propagation remains unsupported.

The product reference carries restrictive producer/duplex metadata; opening its sequence does not make it an ordinary intact input. The source workspace, original inputs, independent original target, original physical run and all immutable events remain retained.

## Documentary records versus current material

`Record` binds schema/engine/scientific-engine versions, original workspace fingerprint, request, derived product event, actual tracked-state revision and inherited origin incompleteness. The stored scientific-engine label is used to reproduce historical context hashes. Known structural records remain readable after a scientific-engine upgrade; documentary validation does not require the current scientific engine or current catalog edition. Unknown structural schemas/record engines, invalid event references, altered bytes and mismatched ownership still fail explicitly.

Current installation and reconstruction require current originating assessments. A historical record can remain in a valid archive while current `reconstruct`, `capsule` and `replay` refuse to grant material until its recipe has been reviewed under the current engine. Fresh replay checks the complete original native product set against its original target, actual cut product reference and retained tracked-state revision. Original incompleteness is sticky; receipts expose bounded original findings (128 entries × 2,048 characters), their full count and an explicit truncation flag.

`FreshFragment` has private, non-deserializable fields with readonly `reference()`, `tracked()` and origin-incompleteness/finding accessors. Only in-process replay constructs it. Serialized `Receipt` and `Record` objects are documentary evidence, not private physical state.

## Closed reuse and integration hooks

`capsule(workspace, product)` first reconstructs the selected exact derived event, then closes its record with the exact original selected-source snapshot. This self-contained `Capsule` is bounded to 8 MiB. Its origin is the existing bounded native run capsule; one of eight ancestry levels is reserved for the new digest derivation. This initial schema selects the exact derived product event, not an inferred matching sequence or arbitrary edited descendant.

`validate_capsule_for_workspace` attests the capsule against the retained record, source snapshot and original native closure before selection. `replay(capsule, fragment_reference)` independently reconstructs its origin and digest, compares the exact product and tracked-state revision, and returns a private fresh receipt. It never restores physical state by deserializing metadata.

The planned typed `ReconstructDigestFragment` operation will consume that recipe; the verifier must retain inherited incompleteness and use actual private tracked state. The source picker must expose the exact derivation event and require deliberate selection. Those shared operation/schema/UI hooks are not supplied by this isolated module.

`validate_workspace_records` is a structural, non-replaying hook which deliberately does not call `Workspace::validate`, allowing use inside archive validation without recursion. `load_record`, `source_bindings` and `required_run_ids` provide explicit typed dependency discovery. Publication/import code must follow those bindings and all closed native runs, and retain the actual derivation attachment. It must not treat this new attachment as a generic opaque leaf or omit source ancestry. The typed [sharing closure](RUN_DIGEST_SHARING.md) now follows this contract for public and native-private selected documents.

The digest scan uses the existing bounded inspection limits; originating science replay remains under its existing independent closed-plan/model/step bounds. The module does not claim a single aggregate comparison budget covering every nested original computation.

Five independent fixture groups cover literal PCR cleavage/end chemistry, actual physical overlap-circle cleavage with inherited incomplete terminal enumeration, retained declared modifications, source/catalog/index/limit/stale-origin refusal and atomicity, native/archive/capsule replay, and structurally readable historical-science records that cannot confer current material authority.
