# Connected multi-parent reference design

This increment connects the finite whole-network model to ordinary assembly and
source-alternative libraries. It retains reference-only scope: complete reference
reconstruction and target agreement cannot establish physical recombination,
inherited strand/modification state, kit efficiency or experimental selection.

## One compiler, independent intent first

`combinatorial_design::Method::MultiSiteReference` carries the complete declared
request and an optional component pin. Two to five exact original parent events
feed the native network. Choice coordinates and orientation independently define
the intended contributions; they do not trim the reaction parents or synthesize
entry constructs. A retained independent target is supported. Otherwise the
existing original-region/junction intent builder runs before discovery. No target
chooses pairings, context families, or a preferred network component.

Inspection with no selection discovers the bounded reciprocal network; it never
substitutes candidate zero. Choosing a component records its native batch revision
and a separate source revision binding stable design/construct/choice identities,
exact parent events, geometry, request and target declaration/content. Applying
that choice does not change the source revision it pins. Equal-DNA events still
have distinct ownership; changed source events, geometry or target invalidate the
pin. Fresh compilation emits the existing typed operation21. Verification remains
Incomplete even on reference agreement; mismatches retain their actual products
and fail agreement.

A reference recipe rejects declared PCR/digest preparation and terminal treatments.
The user may explicitly clear them; the software does not silently reinterpret
prepared physical material. Existing primer text can remain editable draft text.
This is an entry-parent reference workflow, not an attL-tailed PCR shortcut.

## Ordinary and library interaction

The existing assembly dock adds the reference method before intended-construct
review. Users choose source regions and order, review the declared profile,
explicitly select whole original parents without physical preparation/treatment,
and freeze the intended sequence using the existing intent/junction controls.
Network inspection appears inside that frozen review. Candidate/component cards
retain reciprocal inventories and scope/limit findings; selection leads to the
same Plan review or output dialog. Changes invalidate computed evidence.

Ordinary assemblies use an ephemeral single-choice-per-bin projection with stable
namespaced IDs; users need not enable a library for one construct. Role IDs match
the shared compiler before intent is built. Libraries retain their real bin,
choice and construct IDs and use the same method/pin through batch evaluation.
Raw profile settings and explicit choice intent persist as declarations, never
as fresh scientific evidence. Source-owned history remains separate from ordinary
sequence edits.

## Finite three-entry source-edition preset

Alongside the registered1/2 contexts and profile-file import, a reviewable LR
preset supplies nine short functional contexts from p5E-MCS228, pME-EGFP383,
p3E-polyA302 and pDEST R4-R3 VectorII, plus the full pDONR P2R-P3 P3 competitor.
Specificities are4,1,2,3. p5E-MCS is an MCS cassette, not a promoter; the preset
makes no expression claim. It is finite source-edition recognition, not universal
Tol2Kit/Gateway/Pro/ProPlus or commercial formulation coverage.

Only1,188 nucleotide context facts and their source coordinates, orientation and
hashes are bundled; whole plasmids, GenBank annotation records and manual text
are not. The independently written implementation remains MIT licensed. Source
facts and citations do not assert supplier endorsement or relicensing of complete
source materials. [Data provenance](../crates/recombination/data/three-entry-source-contexts.README.md).

The complete96-base L3 context nests within the longer P3 context. Both remain
registered, so all-family maximal-context classification can distinguish their
known source contexts before LR filtering. The preset does not rule out unknown
alleles or unregistered contexts. Synthetic parents made from these literal facts
plus declared test bodies independently test four-scar intent and reciprocal
reference conservation; they are not measured biological kit validation.
