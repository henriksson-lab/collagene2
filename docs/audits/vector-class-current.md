# F36 vector-class source batch — 2026-11-28

The integrated `construct_qc/vector_class/` owner provides two data-defined
declared-graph profiles, ten synthetic native fixtures, binary/MCP integration
and collapsed web controls. Selected native/WASM and scientific/SDK/web-model
checks pass in the connected batch. [Combined compiler and execution evidence](causal-history-current-integration.json).

The exact source and rights ledger is
[data/NOTICE.md](../../crates/core/src/construct_qc/vector_class/data/NOTICE.md).
The rAAV profile is a conventional expression-cassette graph; the SIN lentiviral
profile is an ordinary transfer-plasmid graph with a caller-pinned SIN-labelled
endpoint. Neither claims universal vector architecture or functional identity.
No biological reference DNA is installed.

The single generic engine interprets role minimum/maximum counts, orientation
relative to a declared axis, containment and directed role-order/gap data.
Additional caller spacing constraints retain their rationale. Further profiles
can be curated as data without new vector-specific algorithms. Two declared
qualified ITR roles have opposing feature orientations; this does not verify a
hairpin, flip/flop state or physical nicking. Optional cPPT/WPRE roles are not
universal requirements and their relative order is not invented.

Each binding names an exact source feature, explicit source/annotation-pinned
assumption and a pinned literal reference with source/accession/date/rights.
The engine reuses the existing canonical `Checks::new`, `Checks::assumed` and
`geometry::reference_identity`; there is no second extraction/comparison engine,
finding-order join or prose-based error classification. An actual mismatching
literal remains **ReferenceIntegrity Fail**, while its biological role premise
and dependent geometry remain **Indeterminate**. Missing, stale, unreviewed and
ambiguous premises never become absence. Duplicate IDs or repeated aliases of
one feature under the same role are refused.

Role multiplicity concerns the declared qualified graph, not an exhaustive
biological inventory. Optional caller-specified literal-copy/forbidden-literal
requirements reuse the existing bounded `required_parts` search, complete counts,
orientation/alias handling and work budget. A complete absent literal establishes
only that exact literal's absence. Incomplete searches remain indeterminate.

Users explicitly select two boundary binding IDs and a forward/reverse axis.
The report measures their **outer-edge span**, with an additional interior length
excluding both elements; it never substitutes total plasmid size. Original
half-open spans retain single-turn circular traversal and reverse orientation.
Only exact simple feature intervals establish geometry; unsupported compound or
fuzzy paths keep identity evidence without guessed directed ranges. Order and
spacing require uniquely qualified participating roles and admitted boundaries.

Published size context is descriptive, not a scoring model. The first admitted
range is the4.7–8.7kb **tested plasmid-encoded input range** from the primary
[Wu et al.2010 abstract](https://pubmed.ncbi.nlm.nih.gov/19904234/); no bounds are
compared to the current source to generate pass/fail. No per-kb titre slope or
universal packaging ceiling is present. Radukic's438bp observation is not a hard
distance rule; no NC dataset is embedded. Replication competence, helper/packaging
system design, tropism and host-range changes are outside this module.

Requests bind exact source revision, installed profile identity, annotation and
reference premises, role/boundary/spacing declarations and literal-search limits.
Reports retain source/annotation/assumption/reference/context/report pins, exact reference
verdicts separately from role premises, geometry, source citations and the shared
construct-QC statement. Documentary content hashes do not grant scientific
authority: `validate_for(source, request)` recomputes the current assessment.

Resource ceilings: native construct-QC source admission (two million DNA bases,
256features and existing model/text/extraction limits),2MiB request,4MiB report,
64bindings/references/assumptions/literal requirements,32spacing constraints and
256vector findings. Literal-search work/match limits remain the canonical owner's
current limits. Source trees and restored literal-coordinate trees use canonical
iterative depth guards before recursive serialization; DTO nested vectors are
bounded. A resource refusal does not produce an absence claim.

Fixtures use only authored synthetic four-base elements, including independently
specified forward, reverse and circular coordinate oracles, both profiles,
current/stale/unknown premises, reference mismatch, wrong orientation, declared
spacing, additional qualified nodes, forbidden-literal search and incomplete
search, current JSON roundtrip and direct-owned deep-tree rejection.

Still outside this source batch: repeated-element identity/separation evidence,
transcript-path intron and sense-polyadenylation practice checks, broader licensed
empirical context and integration into worker/MCP/web/protocol output. This is
not full F36 Tier2 completion.
