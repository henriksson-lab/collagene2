# CRISPR guide, selected-reference and donor review

Open **CRISPR** with an active DNA source. **Design CRISPR guides** scans both source orientations using a versioned nominal SpCas9 NGG/20 nt profile, Cas12a TTTV/23 nt profile, or explicitly declared custom PAM, PAM side, spacer length and nominal strand-boundary offsets. These are geometry rules. The interface supplies no empirical efficiency score, cellular cleavage prediction, reagent recommendation or physical cut product.

GC and homopolymer limits are declared filters, not calibrated activity estimates. Candidate and comparison limits are explicit. **Include rejected and ambiguous guide diagnostics** shows possible PAMs, ambiguous spacers and failed filters. Candidate identifiers retain source/profile/coordinate identity across filter changes. The selected guide shows ordered original source coordinates for spacer and PAM, orientation and advisory nominal strand boundaries. **Open guide 5′ position** navigates its exact document/history event. No guide or result is bound merely by matching sequence text.

Off-target searching starts with no selected records. Choose named open DNA records explicitly, or choose **Use source as sole reference**. Optional build and accession labels describe each selected record; they do not establish genome coverage. Selected order defines immutable request roles `reference_1`, `reference_2`, and so on. Source document IDs, exact events, current revisions, labels, profile, query, mismatch limit, resource bounds and workspace epoch bind the search.

**Tag only this selected guide locus…as intended** requires the exact original source event among the selected reference roles. It tags only that role/revision, ordered spacer/PAM coordinates and orientation. Every match remains in the report, including the intended site, additional perfect matches in the same sequence, identical records in other roles, and ambiguous possible matches. Hamming mismatch intervals and PAM certainty remain explicit. Bulges, expression, chromatin, unselected records, whole-genome absence and cellular specificity are not evaluated. A complete enumeration concerns only the selected records under this mismatch/PAM model. Index use, comparisons, retained-hit limits and incomplete searches remain visible.

Guides, reference matches and reference selection are paged in groups of 25. **Expand CRISPR** provides a larger responsive review surface. Coordinate/sequence previews remain bounded; filtering and paging retained evidence do not rerun the scientific search. Exact reference navigation uses document/event guards and can fork a retained event without changing a newer source head.

A donor requires an eligible selected guide, explicit edit start and deletion length, literal replacement, two source homology-arm lengths and a maximum distance from the guide's nominal cut model. A separate open DNA document supplies the independent intended edited target. Empty replacement permits deletion; donor reverse-complement output is explicit. Circular crossing edits preserve source-coordinate evidence and use the core's declared output-origin convention. Arms must be distinct and outside the deleted interval under the bounded one-source-turn model.

**Design and check donor** builds the donor from the original source and literal replacement, then independently checks its arms, replacement, reconstructed edited reference, target comparison and guide distance. The target is never copied into the product. A failed independent check leaves release disabled. The donor is a sequence template, and the edited reference is a sequence design; neither predicts HDR, repair-pathway choice, cellular editing or manufacturing success.

**Export checked donor FASTA**, **Export checked donor GenBank**, **Open checked donor template** and **Open checked edited reference** rebuild the design and run a separate fresh independent check against the exact source, guide, options and target bindings. Opening then checks again inside an atomic native current/recovery transaction. Only the original source event is a product parent. The target document/event/revision remains noncausal requirement provenance in bounded producer JSON. The target and original source heads are unchanged.

Guide, off-target and donor review JSON exports retain the complete structured evidence with exact document/event bindings. FASTA/GenBank lose full event/evidence detail; retain JSON/native data for review. Native products keep their complete donor producer JSON in metadata without defining a new attachment or physical operation. **CRISPR producer provenance · unverified on opening** explicitly distinguishes retained evidence from a current check, including after archive import or browser reload. Imported producer claims never install verification state or private physical chemistry.

Changing any stage's bound source, selected guide, reference roles/labels, independent target, options or workspace epoch invalidates dependent results and terminates pending workers. Explicit cancel controls and unmount also terminate work. Unrelated unselected documents do not become reference evidence. Computation runs in Rust/WASM workers; the application invokes no external scientific executable.

Actual synthetic browser coverage is in `scripts/crispr_browser_qa.py`, including both PAM presets, reverse and circular source coordinates, custom rules, intended/additional/ambiguous matches, limits, cancellation, literal donor and independent wrong-target checks, source-only event parents, atomic failure recovery, native provenance and mobile layout.
