## Endpoint-aware row-band proof

For prefix indices `i in 0..=n` and `j in 0..=m`, define `delta=n-m`, `d=i-j` and radius `r>=0`. The admitted corridor is:

```
L = min(0, delta) - r
U = max(0, delta) + r
L <= i-j <= U
row_start(i) = max(0, i-U)
row_end(i)   = min(m, i-L)       // inclusive
```

Both endpoints belong to every corridor. For unequal lengths, radius zero is a corridor between endpoint diagonals, not a disconnected line. Full and corridor layouts feed the same recurrence. Absent neighbors remain `NEG`; strip edges do not create free starts, restarts or gap closure. Global boundary opening/extension costs, packed predecessor ordering and source-coordinate traceback are preserved. Transposition of longer query inputs retains Insert/Delete remapping and the symmetric proof.

Let `M=max(0,match_score,ambiguous_score,mismatch_score)` and `g=max(gap_open,gap_extend)<0`. A complete path with `P` paired steps and `G` gap calls satisfies `2P+G=n+m`. Every individual affine gap call costs at most `g`, including opposite-gap switches. To leave the corridor and return to the endpoint, a path needs at least:

```
Gmin = abs(delta) + 2*(r+1)
OffBandUpperBound = ((n+m-Gmin)/2)*M + Gmin*g
```

The escape argument is `G>=abs(d)+abs(delta-d)` for a visited omitted diagonal. Parity is exact. Increasing gap calls beyond `Gmin` further decreases this bound. If `Gmin>n+m`, no complete omitted path exists; this is represented as `NoEscapingPath`, not a numeric sentinel. Otherwise checked arithmetic yields a finite bound.

**Only selected score strictly greater than the bound excludes all off-band optima, including off-band ties.** Equality remains unproven. Full-domain evaluation and the admitted exact-symbolic identity shortcut provide their own proof. None of these proves unique correspondence within the retained domain or biological correctness. The independent mathematical review is [affine-row-band-proof-current.md](affine-row-band-proof-current.md).

## Work, memory and whole-comparison scheduling

The existing limits remain: default 16 million cumulative cells per alignment, hard 64 million, default 64 million total comparison cells and hard 128 million. The matrix payload limit remains 96 MiB and output remains at most one million columns. These are not raised to make long inputs appear supported.

`RowLayout` obtains the exact admitted cell count without allocation using checked `u128` rectangle-minus-triangle arithmetic, including on wasm32. It admits packed traceback, two sparse score rows and row offsets before allocation. Full layout uses direct rectangular indexing without an unnecessary per-row table. The previous attempt's grid is dropped before the next is allocated; only the completed path/receipt needed for fallback remains.

One borrowed ledger charges every actual evaluated/initialized DP row cell against both local and comparison limits. Wider attempts recompute cells and charge again. There is no refund or reset per band, origin or strand. Allocation/admission refusal with no evaluated cell does not count as an evaluation. Exact identity and bounded seed scans are not misrepresented as DP cells or sequencing depth.

Adaptive widening uses `min(maximum_radius,full_radius,max(r+1,2*r))`, with checked arithmetic. A strict certificate stops widening; radius/attempt/cell/memory limits retain the last completed actual path with unproven unrestricted optimality. If no attempt fits, the operation refuses. An output-column refusal never returns a truncated scientific path.

Whole comparison evaluates initial admitted bands across the bounded requested origin/strand candidates before spending widening work on unresolved contenders. Only the actual winning path, scalar candidate/attempt receipts and one active grid are retained. An actual incumbent may discharge another candidate when its score is strictly above that candidate's off-band bound: the candidate's in-band optimum is already no better than the incumbent, and omitted paths cannot beat or tie it. This does not relabel that candidate's own path as certified. Existing deterministic candidate ordering governs tied observed scores.

Candidate coverage remains independent. Large circular-reference searches nominate bounded origins from exact seeds; a better untested origin may exist. Missing candidates or unresolved proofs cannot become exhaustive comparison. Exact symbolic equality can attain a global scoring upper bound without enumerating alternative origins, but retains ambiguity/tie warnings and separate coverage flags.

### Bounded inputs, work and coordinate assumptions

Hard limits are 128 KiB request metadata, 32 CDS selections, one million alignment columns, two million aggregate selected coding calls, 64 million semantic mapping operations, 512 register segments and 4096 retained changed/uncertain codon entries. Defaults are one million coding calls and eight million mapping operations. The combined report is at most 32 MiB, and callers may request smaller bounds. Coding-call accounting covers admitted design streams plus projected calls across all rows; mapping work covers actual retained-path indexing/projection, register ordinals and examined projected codons. It is separate from the affine actual DP-cell ledger and never represents read coverage. Admission and bounded-index allocation precede amplification. Coding exhaustion preserves the existing DNA comparison and marks affected evidence incomplete; omitted evidence is never absent.

`ConsensusAxis::StoredTopology` uses the supplied query's stored topology. `DeclaredSingleCircularTurn { rationale }` explicitly permits a conditional coordinate turn without changing the query topology or claiming circular physical stock. A required turn across linear query ends is indeterminate without that declaration, including an ordered joined CDS that skips an intron across the origin. A circular design CDS can map wholly inside a linear query without requiring a query turn. Reverse, joined and natural origin-spanning coordinates follow `BiologicalPath` and actual pairwise transforms; insertions exactly at uncertain CDS/join boundaries are not silently assigned to a gene.

### Current coding evidence and scientific boundary

Each `CdsReport` retains optional native design/projected `TranslationReport`s, separate mapping/register/consequence completeness, bounded register segments and conditional codon entries with original half-open source coordinates. The request still selects a genetic-code ID; output retains `code:construct_qc::CodePin` from the canonical public `CodePin::for_id`, including descriptor, all 64 ordinary amino acids in TCAG codon order and the exact table revision. Documentary validation rejects a changed table even if surrounding evidence is resealed. Initiation, ambiguity, `/codon_start`, `/transl_table`, partial boundaries and unsupported qualifiers remain owned by the existing native translation code.

The query stream is projected from the actual selected CIGAR, not feature labels or another alignment. Intronic insertions stay outside the coding stream when supported boundaries establish that exclusion. Register segments retain paired coding ordinals and modulo-three offsets; a later compensating indel does not erase earlier shifted segments. Parent codon fields remain unavailable where a projected triplet spans design-frame codons. A definite projected internal stop remains definite even when the parent is ambiguous `X`; it is an absolute observation on the selected conditional stream, **not proof that the stop is newly caused by an edit**. `TranslationReport.protein` retains every `*`, including terminal stops.

Globally certified score does not prove unique correspondence, even for apparently unique literals. Every semantic result therefore retains `selected_path_conditional=true`; unproven affine optimum, incomplete origin/strand search, ambiguity, missing annotation bases and unsupported CDS semantics remain visible. No experimental identity, read confidence, native edit causality, annotation inheritance, expression/function or overall biological pass is inferred.

## Read validation remains a separate input contract

[trace_validation](../../crates/core/src/review/reads/trace_validation.rs) uses supported immutable trace or explicit-encoding FASTQ evidence, bounded placements and recorded native-score thresholds. Permitting alignment without qualities does not create eligible scored consensus support. It reports uncovered/conflicting/ambiguous calls, insertions and placement/optimality completeness. [Read checks](../../crates/core/src/review/reads/checks.rs) retain exact reference/read events, and [TraceValidationPanel](../../crates/web/src/reads/trace_validation.rs) opens a marked support-only consensus without copying design annotations or physical stock authority.

Do not reinterpret a provider FASTA as a fictitious scored read, fabricate Phred values, fill unknown calls from the design or label aligned-string fractions read depth. A pairwise path does not establish mixed-clone status, contamination, structural-rearrangement classes, sample identity or experimental confirmation. No new scientific tables, third-party code, raw-read pipeline or external engine is introduced by this work.
