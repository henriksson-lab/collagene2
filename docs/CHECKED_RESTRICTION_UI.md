# Checked restriction and ligation in the web interface

In **Plan**, select the independent active target, choose source documents and select **Restriction and ligation**. **Restriction model** offers the existing **Assume complete cleavage (legacy)** path and **Check inherited modification state**. Existing manual designs default to the legacy choice; enabling checked state is an explicit action.

Checked mode binds each source role to its exact document, history event and molecule revision. Declare Dam, Dcm and CpG source generation independently for each source: unknown, assume unmodified, assume fully modified, or unsupported hemi/mixed. Defaults remain unknown. The pinned positional profile revision and supplier formulation identities are visible. This profile is distinct from the F21 source-context review; generic and newer HF/v2 formulations are not interchangeable.

The positional model is closed to these three modification systems. It assigns original eligible motif positions under the declared source generation. Original positions outside those motifs and newly synthesized bases are unmodified under this scope. Digest, reverse orientation, repair and ligation propagate actual strand positions; descendant motifs are not rescanned to infer methylation. Other modification systems, actual physical reagent histories and measured modification state are not established.

The ordered plan explicitly declares each original input, applies **CheckedDigest** with its pinned profile, selects a fragment in ascending top-cut order, optionally repairs its ends, applies terminal treatment and ligates the selected substrates. **Final restriction product** offers a single processed fragment without ligation, or an explicit ligation. In ligation mode, **Use a second restriction substrate** may be unchecked for single-substrate self-circularization. The active target remains a separate comparison. It is not automatically a product parent. Optional end repair fills 5′ overhangs, removes 3′ overhangs or does both; it does not silently repair internal nicks.

Blocked sites remain uncut under the positional model. A blocked circular input remains an intact circle. Single-fragment mode can retain that unchanged circular digest product; ligation mode cannot treat it as a free-ended fragment. Unknown or impaired cleavage withholds undetermined products. Partial or target-mismatching reconstructions cannot be retained as complete runs. The existing explicit incomplete-run gate remains available only for fully materialized, target-matching products with incomplete checks; it cannot fabricate missing products.

The reconstruction view retains checked findings, source assumptions and positional producer summaries. Summaries show strand lengths, chemical-call counts and state identity; they are display evidence, never reusable authority. Imported summaries do not install private positional state. Verification reconstructs state from source declarations and the ordered operations on every run. **Download reconstruction report** exports bounded JSON; candidate, HTML/PDF protocol and native workspace exports retain the ordered operations and profile binding.

Pending reconstruction is invalidated by changed assumptions, fragment/repair/treatment/orientation choices, exact target or source event identities, or workspace epoch. Identical-content documents do not inherit another document's pending result. Manual designs pass their exact selected source-event bindings to the retention dialog; imported or ambiguous candidates still require explicit event choices. Retained product steps have their causal source-event parents. Native reopening restores historical producer evidence; fresh replay is required and never proves experimental provenance.

Developer coverage is in `scripts/checked_restriction_browser_qa.py`, against synthetic circles and literal repaired targets in the actual WASM worker. It checks blocked, permitted and uncertain outcomes, imported-summary nonauthority, repair/ligation propagation, independent targets, record gates, exact source parents, native replay and readable protocols.
