# Reference-free read assembly in the web interface

Choose **Read assembly** and select open linear DNA read documents. There is no external reference document or intended target in this workflow. The picker distinguishes documents by stable IDs; the selected order defines explicit `read_1`, `read_2`, … roles. Changing that order, any selected document's exact event/revision, options, or workspace epoch invalidates the result and terminates its worker. Identical sequence content in a different document does not inherit another document's pending result.

The workflow accepts native trace and explicitly encoded FASTQ evidence, and offers a separate **Explicitly allow unscored read calls** declaration for plain DNA. The checkbox starts unchecked in the web interface. Trimming controls use the source's native raw scores and an explicit window policy; ABIF/SCF values are not automatically interpreted as calibrated error probabilities. Each read report retains source, trim, original-call/orientation and quality-policy information, with errors and duplicate-evidence groups visible.

**Assemble contigs** runs the embedded Rust assembler in an isolated worker. Minimum overlap, allowed non-certain columns, affine scoring, strand policy, consensus support and resource bounds are explicit. **Cancel contig assembly**, option/source changes and unmount stop pending work. A limit is an incomplete search, not evidence that no other overlap or contig exists.

The **Overlap graph and alternatives** section draws and lists directed overlap records in pages of 25. Orientation, paired/error counts, score, tied-path count, selected/alternative/excluded status and reasons remain inspectable. Opening an edge displays its actual gapped pairwise strings. The current graph drawing represents that page; the full retained edge set remains in the other pages and JSON report. It does not silently collapse all alternatives into a unique biological molecule.

Select a contig to inspect its bounded layout. The Canvas viewer paints at most 160 columns and 12 read rows, with column jumps, keyboard selection and row/column paging. Original source molecules are not cloned or scientifically reassembled during viewport movement. Exact column evidence remains available in pages, including consensus state, A/C/G/T counts, gap evidence, eligible calls and current/original call and trace-sample coordinates. Layout arrows refer to current read orientation; placement details also show original attachment orientation. Unresolved calls remain explicit; no bases are supplied by an external reference.

**Open source call** navigates by exact document/event/revision, not by matching sequence text. If the source head has advanced, the retained source event is opened as a new fork without changing the original head or undo/redo. Cross-document selection waits until normal source-change effects settle and checks the workspace epoch and target event again. A newer active document or selection cancels that deferred selection.

A consensus with incomplete search, unresolved calls or non-unique layout requires an explicit acknowledgement before use. The interface does not enable consensus release where the core supplied no reconstructed molecule. For a current read selection, **Download contig FASTA** and **Download contig GenBank** rerun assembly from the exact reads/options and compare the selected product before export. A historical report requires an explicit fresh session replay and retained-source binding check before text export. FASTA omits quality/call/history evidence; GenBank comments are bounded producer summaries. Retain the complete report and native workspace for exact reconstruction.

**Keep assembly evidence** also works when a graph is ambiguous and no consensus is opened. **Open reconstructed contig** opens a review dialog that records the report and the optional product together. **Record read assembly** reruns the assembler against its bound retained events, validates the new workspace, then atomically replaces IndexedDB current/recovery slots. The pre-recording workspace becomes the recovery copy. Failure or stale state leaves the original workspace installed. Source heads and undo/redo are preserved. A new consensus document has every contributing source event as a parent; evidence metadata does not create physical chemistry or verification authority.

History lists **Saved read assemblies** from native attachments. They open as **Historical producer evidence · unverified on opening**, including after reload or portable archive import. **Replay saved read assembly** resolves the original event snapshots even when current heads are newer, computes a fresh report in a worker and compares engine/product membership. Only that session replay enables consensus use. Restoring a report does not restore a positive verification cache. A new archival transaction checks again before installing a product.

The report JSON has a bounded 32 MiB browser serialization limit. Native attachments retain the complete structured report once with exact source-event bindings; original chromatograms/FASTQ evidence stay on their source revisions. The application invokes no external scientific executable. Developer coverage is in `scripts/contig_browser_qa.py` against isolated local Chrome and synthetic sources.
