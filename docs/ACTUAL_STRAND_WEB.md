# Actual-strand assembly contributions in the web workspace

A saved digest fragment can contribute its actual stored top or bottom strand to an independently declared intended construct. Reversing the contribution chooses the opposite actual strand; it does not manufacture a complement from the displayed top reference.

The current draft stores one typed selector per slot. Reference selectors retain the ordinary original-reference coordinate model. Material selectors retain the strand's local 5′→3′ interval and expected native state revision. Digest handoff also keeps the small source domain needed to select the other actual strand, the exact captured source event, its original molecule, the catalog choice, and its Run or Derived origin. Neither a padded top sequence nor a synthetic source molecule is introduced. Draft schema16 requires the selector directly; obsolete interval-shaped drafts are not converted.

The intended-reference worker receives the retained native workspace for material selectors. Its fresh source resolver checks the event, origin, state and interval before reading the selected strand. The intended target is declared from those original strand calls and literal edits before the assembly preparation is simulated. Physical row reversal still applies to the actual prepared duplex through the existing FromRun/FromDerived recipe.

The source card shows selected strand-local coordinates and a paginated 5′→3′ sequence. Its native original-contribution receipt is ephemeral, keyed to the captured source, selector and origin, and invalidated by workspace epoch changes. Substitution and indel controls use that original receipt across literal edit changes; they never read expected letters back from an edited target. Material contributions must be reviewed once before those source letters are available for editing.

Original-reference navigation stays in the displayed top-reference domain. It highlights only genuine native top mappings. Extra bottom-strand bases remain visible in the actual-strand strip and intended target, with no fabricated top coordinate, feature, wrap or highlight. Navigation does not rewrite the original source molecule. A top-view selection must map unambiguously to the contribution before it can seed an edit.

Primer proposal controls explicitly require reference-range selectors until their template model supports actual physical strands. Source alternatives and combinatorial projection likewise refuse material selectors in this slice; ordinary saved designs retain them directly. No interval is silently substituted to make a proposal or library projection fit.

## Native fixture coverage

The connected web-model fixture starts from independently supplied strands:

- top21: `AATTGCTACGGAATTCTTACG`;
- stored bottom21: `AATTCGTAAGAATTCCGTAGC`, placed at top-axis +4;
- selected EcoRI fragment: top [11,21), bottom top-axis [15,25).

Reversal selects original stored bottom [0,10), yielding exact intended sequence `AATTCGTAAG`. Its first four bases have no original top-reference mapping; original top [15,21) maps in reverse to contribution [4,10). Reversing twice recovers the initial selector. The fixture exercises both saved Run and target-free Derived sources, actual reverse ligation, independent intent staging, native archive restart, retained source heads, original-letter edit capture and stale-state refusal.

`CGTAAGAATT`, the guessed RC of the selected top interval, differs as an exact linear coordinate string but is a rotation of the same10-base circle. The negative independent circular target therefore uses a true point mismatch, `AATTCGTAAA`, rather than confusing a valid circular rotation with an incorrect biological sequence. Browser rendering is not established by these native fixtures.
