# Golden Gate junction edits with retained preparations

`golden_gate_junction_edit` combines independently declared source trims/literal inserts with selective Type IIS primer preparation. Its target comes only from the existing source-coordinate junction intent builder. PCR/digest or ligation output is never copied back to define the expected target.

Each ordered row is either `Retain(ligation_recipe::Fragment)` or an explicit selected `DesignPcr` with source role/input/orientation and original forward/reverse annealing lengths. Roles and order must match the base intent. Retained rows must carry a pinned `CatalogDigest` or `PcrCatalogDigest` for the chosen Type IIS enzyme and exact embedded geometry. Their full preparation, chosen fragment, primer names/tails, optional repair and end treatment remain unchanged. Retaining a row is not a claim that it remains compatible with the edited intent.

The chosen enzyme determines the fusion length: BsaI/BsmBI/BbsI use four-base ends, SapI uses three. Clamps and cleavage spacers are explicit concrete operator choices. For a selected row, the outgoing desired assembly-top fusion is the next adjusted oriented original core's prefix; circle closure uses the first core. Only a selected **final linear** PCR row requires an explicit `terminal_right_overhang`. Every other case requires `None`, including a retained final linear row, so no unused terminal sequence is invented or silently ignored.

If `T` is clamp + recognition motif + profile-sized spacer, `F` is that outgoing top fusion and `I` the upstream row's literal inserted suffix:

- A forward row's original reverse primer receives `T + reverse_complement(F) + reverse_complement(I)`.
- A reversed row's original forward primer receives the same addition. Its reverse primer retains the existing `T + reverse_complement(original_core_last_k)` arrangement, and its PCR interval excludes the original last `k` source bases as in the established designer.

The existing source-bound unique-PCR and actual physical digest algorithm is shared through a narrow internal row helper. It requires the exact nominated original-source geometry, uniquely reconstructs PCR, rejects extra/internal recognition sites, identifies the actual retained fragment and checks both oriented ends. Its right cut is at `left + original_core_length + inserted_length`. The retained oriented top must be exactly `oriented_core + I`; reversal uses the real retained opposite-strand projection, not a guessed reverse-complemented top fragment.

The new `Design` exposes actual primers, selection/index, retained top and both ends. Its own five-part `TailSegments` distinguish clamp, motif, spacer, fusion and inserted sequence, all written in the oligo's actual 5′→3′ direction. `sequence()` concatenates these fields in that order. The original standalone Golden Gate DTO remains four-part and unchanged; its public design path calls the same helper with an empty insert. A temporary internal old row is never validated or exported as an old report when it carries a nonempty junction insert.

Shared intent permits up to 200 normalized bases per junction insert and 400 raw ASCII bytes, with 4096 inserted bases overall. New primer preparation is constrained by the **actual complete 200-base ordered-oligo limit**, not an arbitrary 100-base insert cutoff. Thus an insert longer than 100 bases can be proposed with short enough domains/tails, while an actual 201-base ordered oligo is rejected. Existing concrete source rules, model limits and source/target budgets remain in force. Preflight reserves binding work plus insert-extended amplicon/digest scan work before source copies or scientific scans; selected output remains bounded. No dummy target is used to preflight retained rows.

The returned ordinary ligation recipe uses original input documents, selected actual PCR→pinned-digest preparations, unchanged retained rows and the explicit nick policy. Fresh full ligation verification against the independent intent remains a separate required step. Selected local geometry supplies no reaction-yield, methylation-clearance, kit-condition, empirical-activity or exhaustive mixture-specificity guarantee. Internal sites and unwanted fusions are not automatically domesticated or optimized.

Readonly report checks bind original source revisions, request/intent, exact retained bytes, actual complete oligos and tail segments, enzyme pins/index, retained top, end polarity/terminal groups and explicit ligation policy. Imported JSON cannot restore physical graph authority or a current scientific verdict.

Five focused fixtures specify independent inserted circles with BsaI four-base and SapI three-base ends; reversed source preparation with a nonpalindromic insert; trimmed linear output and explicit selected terminal fusion; preserved incompatible repair choices; valid 110-base inserts and the exact 201-base oligo refusal; stale/tampered/internal-site failures; and the old public empty-insert helper behavior. Original inputs remain immutable. No new scientific operation, candidate/plan schema or verification engine version is introduced.
