# Interactive sequence dot plots

Open **Dot plot** and select an open query document. The active document is the reference. A new panel starts with a self-comparison and a visible window length no larger than either sequence. The query selector includes stable document IDs, and **Source identities** exposes the exact retained source events. Both sequences must use the same explicit alphabet. Protein plots use forward residue coordinates and disable reverse complement; DNA/RNA plots support both strands. Changing the source to another alphabet selects a compatible self-query if the old query is incompatible.

**Calculate dot plot** runs the bounded Rust window comparison in a worker. The interface accepts a window length, allowed incompatible positions, a start stride, both nucleotide strands, circular-origin handling and explicit work/hit/index budgets. At least one compatible position per window is required. Ambiguity-compatible matches remain distinct from threshold support by certain singleton matches. The panel labels the sampled-grid and full-domain completeness flags separately. An incomplete or sampled empty area is never an absence claim.

The interactive view uses **one anchor per retained qualifying window**: x is the original reference position aligned to the first query position, and y is that original query position. The centers are drawn at `(reference_start+0.5, query_start+0.5)` in zero-based source coordinates. Forward, reverse-complement and ambiguity-dependent anchors have separate colors. This is not a gapped alignment path or a read-coverage estimate.

The WebGL2 vertex buffer stores raw integer source indices (the core's maximum 10,000,000 is below the exact f32 integer limit). Pan/zoom uniforms split the camera origin into an integer and a fractional component; the shader subtracts integer positions before applying fractional offsets. This preserves base-level positions at high coordinates without rebuilding the buffer on camera movement. Rendering is coalesced through animation frames. Axes and selected-window trajectories use a Canvas2D overlay; selected trajectories split at each circular-origin crossing rather than joining opposite plot edges.

Drag to pan, wheel to zoom around the pointer, or use the **Fit**, **Zoom in** and **Zoom out** controls. With the canvas focused, arrow keys pan, `+`/`−` zoom and Home fits both sequences. **Expand plot** opens a larger workspace region; Escape or **Close expanded plot** restores its inspector size. Plotting does not alter either source document.

Click an anchor or choose a window from the accessible list. All retained windows are available in pages of 25, including coincident anchors. Inspection shows exact original-source spans, orientation, compatible/certain counts and bounded source sequence previews. The UI displays one-based inclusive spans; exported report spans are zero-based half-open. **Select reference window** highlights every reference span, including origin-crossing pieces. **Open query window** explicitly opens the query document and selects its original spans; the changed active source invalidates the old analysis.

If WebGL2 is unavailable, the Canvas drawing combines all visible retained anchors in a declared 64×64 display grid. This changes only drawing resolution. The full exact retained window list and exports remain available. The fallback notice is always visible; no scientific matches are silently removed to make the view appear complete.

**Download dot-plot JSON** exports the complete bounded scientific report, including both source revisions, options, engine, exact retained windows and limits. **Download dot-plot SVG** uses the core's full-window trajectory export with explicit origin splitting; its window segments and the interactive view's first-position anchors are two representations of the same retained windows. Neither representation restores verification authority or establishes physical identity or common ancestry.

Reference and query molecular revisions, exact document/event identities, all options and workspace epoch bind each pending request and every export action. A source/options change terminates its worker, clears the result and ignores obsolete replies. Identical molecular contents in different documents do not bypass these guards. Unmounting the panel also terminates pending work. Report binding checks do not rerun the expensive scientific search on the main thread.

Development checks are in `scripts/dotplot_browser_qa.py` (Python `websocket-client` and Pillow are development-only prerequisites). They use independent finite-window oracles and synthetic sequences in the actual WASM application, test WebGL drawing and camera movement without buffer uploads, exercise the disclosed fallback, and cover DNA/RNA/protein coordinates, origin wrapping, limits, exact-source cancellation, JSON/SVG and mobile layout. Native camera tests compare f32 shader arithmetic with independent f64 positions near 10 Mb at one-base zoom. The application invokes no external scientific program.

The local headless Chrome/SwiftShader run retained all 29,986 exact windows in a complete 30 kb self-plot, verified visible anchor pixels, and observed 16.666 ms p95 animation-frame intervals during camera zoom, with zero vertex-buffer uploads during that motion. This is a local software-renderer observation, not cross-browser, hardware-GPU or 10 Mb acceptance. Both reference-origin and reverse-query-origin span navigation checks passed on the rebuilt application.
