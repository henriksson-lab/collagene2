# Reaction quantities in the sequence workspace

Reaction quantities are available beside an opened retained candidate and in a saved run review. The form starts with no reactions or amounts. Add the operations and components you want to describe, enter direct volumes or a declared mass/molar dilution, and review the result before saving. Missing amounts stay unspecified. These calculations do not change sequence verification or establish reagent availability, measured concentration, isolation, or experimental success.

Each record retains the exact plan revision, independent target event, and ordered input events. Saved-run records use the run's retained bindings even when the visible source or target has since advanced. Candidate records require the exact candidate to remain in the workspace; quantities never silently create or replace a candidate. A material reference can name only an operand actually consumed by the chosen operation. Reagents without a biological source use an explicit label and no material reference.

Direct volumes accept explicit µL, nL, or mL units. Mass dilution uses ng/µL; molar dilution uses nM or µM. Decimal input becomes exact rational values through the shared units library. Optional rounding requires a declared increment and rounding mode; the review retains the achieved concentration as well as the requested concentration. An optional fill component receives the explicit remaining volume. Overfill, absent values, and invalid dilution remain findings rather than becoming zero or a recommendation.

Review, saved-record listing, opening, capture, and exports run through the native worker. Listing returns bounded summaries; the interface filters those summaries by exact plan and event bindings without replaying every quantity record on render. Binding availability and arithmetic completeness are separate. Records whose plan or events are missing remain visible as unavailable, while other saved quantities can still be opened.

Saving validates the current workspace scope, receives the immutable native capture, and persists the full workspace with current/previous recovery through the existing storage transaction. The interface reports success only after the storage acknowledgement. Restoring the resulting workspace deliberately clears current scientific review. A parent-owned message confirms the save and directs the user to reopen the run or review the retained candidate. No scientific receipt survives that reset as current authority.

Standalone quantity CSV/HTML/PDF and combined cloning-instruction HTML/PDF exports use the saved attachment's native export operation. Context, selected record hash, and format are checked before delivery; the source scope is checked again at export admission. Completion follows the actual file-save acknowledgement. Combined exports show the fresh molecular result separately from quantity completeness. Dilution review shows readable exact additions, rounding deviation and achieved concentration; findings are paginated. Export warnings remain visible. The native workspace archive retains the quantity attachment and its exact bindings; ordinary single-plasmid publication does not imply publication of quantity reports.

## Verification scope

The pure web model fixtures exercise missing amounts, exact fill and overfill, invalid decimals, explicit dilution quantization and achieved concentration, retained inactive raw input, operation-operand restrictions, and real saved-run event bindings. The native archive fixture advances source and target heads, rejects an equal-DNA event alias and stale epoch, then captures and reopens quantities while retaining the original run bindings. Browser behavior is not claimed by these fixtures.
