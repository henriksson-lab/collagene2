# Actual source strands in independent assembly intent

A contribution has one selector. `ReferenceRange` names a displayed original DNA interval and its explicit reverse-complement orientation. `MaterialStrandRange` names stored 5′→3′ offsets on an actual native top or bottom strand, pinned to its modification/state revision. These are different coordinate domains. A material interval is never converted to an original-reference PCR interval; primer consumers must deliberately select a supported reference interval.

The four intent layers accept one required-nullable workspace argument last. Material selectors require the exact workspace and one `MaterialBinding` per input. Preflight charges the complete mixed Run/Derived origin graph before hashing or copying it, attests exact event/native ownership and full source snapshot equality, and then the private resolver replays each distinct exact event/selected native owner once. Different equal-DNA events remain different sources. Repeated roles using the same attested source share the resolved state. No planned assembly product or desired target supplies its sequence.

A bottom selector reads actual bottom calls, including bases beyond the displayed top. For a source top `AATTGCTACGGAATTCTTACG` and bottom `AATTCGTAAGAATTCCGTAGC` placed at +4, the right EcoRI fragment has top coordinates 11..21 and bottom coordinates 15..25. Its reversed contribution is stored bottom 0..10: `AATTCGTAAG`. Reverse-complementing the displayed top fragment would instead give `CGTAAGAATT`. Those are different linear origins even though this particular circular ten-base product makes them rotations. Physical verification remains a separate native reconstruction/digest/reverse-ligation plan against the independently declared target.

`PlacedFragment.selector` and `original_sequence` describe the ORIGINAL unedited oriented contribution. `retained_start/end` express junction trims in those original construct-oriented offsets. Substitution and indel literals are checked against this original sequence; output coordinates describe the resulting edited target. `source_position` returns typed Reference positions or Material strand offsets, never an ambiguous integer.

Source-top annotation mappings are original source top coordinates to ORIGINAL contribution-local coordinates. Only actual paired/corresponding positions receive projected annotations. In the example source top 15..21 maps, reversed, to output 4..10; the first four bottom-only calls receive no invented top annotation. Clipping uses retained offsets, and edited coordinate/function qualifiers keep their review restrictions. Unprojectable or oversized annotations remain in the source, with explicit warnings instead of invented target coordinates.

The plain request occurs once in each report. Nested intent builders borrow the same resolved context and small retained layouts; they do not construct adjusted requests containing duplicate closed origin arrays. Full original selected DNA occurs only in report source evidence (aggregate eight MiB), not target metadata. Target descriptors contain bounded selectors, event/state/domain/mapping descriptors and hashes. Reports have a bounded serialized 32 MiB scope, with frame reserve. Closed native ancestry retains its independent aggregate limits.

`material_source_descriptors` is the one current descriptor parser. It validates documentary shape/hash, not scientific or sharing authority. Sharing must first establish each descriptor event is already in the target's REAL native history ancestry, and independently attest its exact native Run/Derived selected owner. A metadata hash, copied descriptor, source name or equal DNA must never expand a publication graph or restore private physical state.

The intended molecule remains explicitly reference-only. Read-only report checks do not rerun chemistry and cannot materialize DNA. Staging still requires the exact current workspace/source/epoch and native history parents. Native physical preparation, PCR/assembly compatibility, independent target verification and experimental isolation remain separate decisions. Incomplete origin findings remain visible; reading a strand neither completes its search nor proves isolation. Linear material ranges stay within the selected stored strand; only an actual circular native duplex permits one unrolled turn.
