# Declared research-vector profile facts

The independent implementation and small factual curation follow the repository
MIT licence. No biological reference sequence, supplier artwork, article,
parameter dataset, helper-system design or production protocol is redistributed.
All literal element references are explicit caller inputs with exact sequence
revision and source/accession/date/rights provenance.

The installed `profiles.json` contains scoped **declared annotation graphs**.
Neither a role name nor an identity match authenticates an element's biological
role or source provenance. In particular, the SIN label is an assumed premise;
no deletion adequacy, functional self-inactivation or replication-competence
assessment is made.

Addgene's live guide sources have no immutable upstream byte hash in this
curation. Profile identities bind the exact installed curation and captured
source metadata; they do not authenticate arbitrary future web content.

[Radukic et al.](https://doi.org/10.1093/nar/gkae1170) reports438bp as the shortest
stable ITR-to-origin distance in its particular experimental setting, rather
than a universal safe minimum. The article is CC BY-NC4.0. No table, sequence,
host/culture recommendation or stability prediction is installed from it. Repeat
identity/distance, transcript-level intron/polyadenylation practices and further
empirical size studies require their own source-bound admission; they are not
silently treated as covered by these graph profiles.
