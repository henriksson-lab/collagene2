# Upstream material as a TOPO PCR template

A `TopoActions` source can now refer to a prior plan step when that role is used
only as the template of an explicit `ExactPcr` material recipe. This connects
freshly reconstructed upstream material to the existing TOPO preparation,
processing, contour, downstream operation and retained-output route.

The private verifier resolves actual tracked material for the exact dependency.
It requires matching top sequence/topology, complete aligned complementary strands,
no stagger and no nicks. Every upstream role must be used by at least one PCR
recipe and by no `Prepared` source interval. Unused roles, forward/cyclic sources,
reference-only ancestry and absent private material are rejected. The existing
public standalone source APIs remain strict; an imported physical summary or a
matching DNA string grants no exemption. No producer metadata is stripped.

This is new synthesis. Template modifications and generation history are not
inherited into the new PCR strands. The existing graph-to-duplex bridge retains
conservative Unknown internal modification calls, including the newly copied
portion; this increment does not claim that the complete selected product has a
closed unmodified-state model. Activated vector declarations, cleavage and ligase
availability remain explicit hypotheses. No upstream source atoms or arbitrary
prepared-strand ancestry are inferred from sequence correspondence.

## Review, evidence and formats

Generic native/MCP plan verification accepts this composition through the existing
`TopoActions` declaration. Its original `Source::Step` dependency remains in the
plan, HTML/PDF and full typed report. Existing standalone TOPO inspection continues
to require original source inputs; there is no public API accepting a serialized
tracked material as fresh authority. Direct preparation-panel selection of an
upstream plan step remains UI work; imported sequence documents are not a shortcut.

Historical graph attachments resolve each upstream identity against the exact
prior retained product step/event/revision. They never substitute plan input rows,
current heads, document names or equal DNA. Workspace archive and fresh replay
preserve both intermediate and final products. Re-keying a changed historical
source identity cannot transplant evidence onto another event.

Worker67/candidate15/plan13 introduce this semantic capability; the fresh verifier
is science18. No report, operation, RunRecord or RunReceipt fields/ordinals change.
Existing worker66 report layout and original-input operation20/candidate14/plan12
remain readable at their original floors. Source-bearing operation20 requests
need67, and science18 reports cannot masquerade as66. Existing positional migrations
through65 remain intact.

## Validation and boundaries

The independent fixture starts with a CpG-modified native template, explicitly
copies its ten-base sequence through PCR and reconstructs the frozen 24 bp TOPO
circle. All 52 preparation calls remain accounted for: 48 in the duplex and four
in the free fragment. Template modifications remain on its retained upstream
product; the new product receives no inherited modified calls or generation record.
Wrong independent targets, marked ordinary inputs, mixed Prepared/PCR use, unused
roles and nicked/staggered templates are exercised separately. Binary capability
floors, exact upstream history, archive/replay and changed-sidecar rejection are
covered by the same focused fixture family.

Validation passed: 66 focused native cases across source adapters, old/new TOPO
plan verification, positional migration and version gates, upstream material,
history and real MCP SDK calls. The application/worker WASM check and formatting
checks pass. Core/MCP/web test fixtures also compile. No application browser
checks or full preview rebuild ran.

Actual atom-inheriting upstream preparations, modification mapping through their
source intervals, broader methods/chemistry, durable graph-only review, direct
preparation UI composition and remaining delivery/GUI acceptance stay active.
