# Oligo output from exact cloning plans

`collagene_core::plan_oligos` extracts declared order data without running PCR, digestion, annealing, target comparison or another biological algorithm. `build(plan, target, &Options)` binds the exact plan and its separately bound target. `Options { deduplicate: true }` is the default. Borrowed model, scalar/string, original revision and target guards precede model hashing/copying and original-row decoding.

`Report` contains plan/target revisions, options, `complete`, `unavailable`, an existing `oligo_formats::OligoTable`, per-use evidence and warnings. PCR and mismatch-PCR steps contribute their actual forward/reverse names, 5′→3′ annealing domains and tails. Each `OligoUse` keeps step, kind, source, original name, full original `Primer`, mismatch policy when present, and its generated order-row ID. A different domain boundary is never erased merely because ordered DNA is identical. IUPAC remains degenerate sequence, not a concrete oligo.

Deduplication groups only equal normalized ordered DNA and equal explicit modification data. Every usage remains separate. Distinct sequences with colliding names have distinct row IDs. When grouped uses have differing domain/tail partitions, primary order-table domain columns are blank and a warning points to exact per-use evidence. The row's primary name is its first label, not an invented merged identity; name previews and complete uses preserve the other labels. Deduplication does not imply the same experiment, quantity or binding behavior. Generated row IDs identify data rows, not supplier products or stock.

No PCR `Primer` field specifies an order modification or quantity, so none is inferred. In particular, downstream phosphorylation, end repair, ligation or an intended target never creates `/5Phos/`, supplier codes or synthesis requests. Original `AnnealOligos` inputs can contribute literal bounded DNA, but declared starting termini are state assumptions rather than supplier instructions. They stay only in per-use `declared_terminus`. No annealing partition is guessed for an entire anneal-input oligo. A derived `Source::Step` is produced by the plan and is not silently ordered as a new synthesized oligo; available upstream PCR primers remain listed.

Original oligo-table metadata must replay through the existing strict parser, original-row hash/mapping and actual current DNA before it is used. The current parser treats modification annotations as opaque. Such order data is explicitly unavailable rather than flattened to unmodified DNA or translated to an invented supplier notation; the complete original source stays in the plan. Missing/corrupt source records, unsupported original oligo geometry/length, and embedded TOPO preparation oligos outside this typed-PCR profile also produce `complete: false` and explicit `unavailable` diagnostics. No empty oligo IDs are manufactured for unavailable orders. Ordinary PCR plans with all declared oligos represented are complete; completeness is about this order-data profile, not experimental success or molecular-plan validity.

`export(plan, target, options, delimiter)` returns `Exported { context_revision, report, export }`. Delimiter is existing `Comma` or `Tab`, and output always uses `TableExportMode::SpreadsheetSafe`. `export_revision(...)` binds the plan, actual target, options and delimiter; `Exported::validate_binding(expected)` checks bounded readonly receipt structure and context. It does not reconstruct a plan or establish imported positive authority. JSON evidence retains original names/fields even when spreadsheet cells receive a protective apostrophe. HTML/PDF protocols continue to come from the existing verifier/protocol APIs, not from an order sheet.

A host should not automatically download an all-required order sheet when `complete` is false. Show unavailable diagnostics and retain partial data for explicit review. The order table and use evidence are a matched pair, particularly when a domain partition or name differs between uses.

Limits: at most 1,000 typed steps, 128 original inputs, 2,000 declared uses; PCR ordered primers at most 200 bases; bounded original anneal rows at most 8,192 bases within the existing cell profile; canonical table 8 MiB and complete report/export receipt 32 MiB. Existing borrowed source guards also limit aggregate original/target DNA and model annotation shape. Warnings and previews are bounded. These are application limits, not an operating-system memory sandbox.

Source-authored core fixtures cover exact tailed/domain-partition dedup, colliding names, mismatch policies, formula-safe CSV/TSV, non-deduplicated rows, context changes, stale revisions and deeply nested native annotations. Anneal cases show that starting 5′ phosphate does not become an order modification and that opaque original modification data prevents complete export. MCP fixtures use an actual saved plan and its stored target, preserve original documents and distinguish order data from target verification. Fixture execution is recorded separately.
