# Domestication from exact saved native material

`domestication_preparation::Request` retains the independent genetic design,
selected literal substitutions and physical route, plus required-nullable
`origin: Option<MaterialOrigin>`. `None` means an ordinary original reference;
marked physical evidence cannot use that path. Run and Derived origins retain
their exact source event and complete native ancestry, not a sequence-equivalent
replacement or supplied duplex summary.

`preflight`, `revision` and `materialize` take the owning
`Option<&Workspace>` last. A saved origin requires that workspace, its exact
retained native owner and a complete source-snapshot match before origin copying
or science. Current source heads need not replace the deliberately retained event.
The caller still pins the selected source event and workspace/epoch at admission.

The selected genotype is checked and frozen before primer planning. Single inverse
PCR uses the current source-origin compiler. Sequential rounds prepend one native
reconstruction, then each PCR consumes the preceding actual circular ligation
product. Original-coordinate substitutions and reverse-tail product-origin shifts
remain explicit. Intended intermediate frames declare oligos only; they never
become physical template inputs.

OE preparation plans primers against one freshly reconstructed actual Top frame,
reserving its real source/work bounds. Both first PCR branches consume the same
reconstruction step; extension and outer PCR consume their actual predecessors.
Circular outputs append explicit phosphorylation and intended ligation. No target
DNA chooses a primer geometry or supplies recoded stock. Nicked or unsupported
source geometry is withheld rather than repaired automatically.

There is one canonical plan. The OE method evidence retains `context_revision`,
`source_frame`, `preparation`, `designs` and `search`; its request is derived from
the canonical outer request rather than duplicating the closed origin.
`Prepared::validate_binding(expected)` is workspace-free documentary validation:
it checks exact source, independent target, declared graph and frame/primer/search
correspondence without reconstructing material or repeating primer search. Fresh
verification establishes actual source material and inherited limitations.

Only newly performed PCR oligos enter the new primer collection. Original native
assumptions and incomplete findings remain in reconstruction evidence and cannot
be cleared by target agreement. Primer-proposal readiness concerns declared design
constraints, independently of molecular consistency or experimental success.

The current compiler stamp is `domestication-preparation-3`; documentary review
attachments use only `domestication-intent-v3`, version3. No previous internal
shape is decoded or converted. Original source documents/heads, historical runs
and their assessments remain unchanged by preparation.

`crates/core/tests/verification/preparation/domestication_saved_material.rs` covers real Run/Derived restart,
inverse and linear/circular OE, dynamic sequential-round dependencies, new-only
primer orders, native saved-run replay and HTML/PDF, exact-owner/event refusals,
actual nicked sources and a genuinely search-incomplete native origin. The integrated batch passes193 selected native/SDK/model cases and the web/worker
WASM compiler check. GUI and laboratory acceptance are separate and remain open.

OE order export retains six primer uses. Identical ordered DNA can share one
order record, so a collection may contain fewer than six unique oligos. Historical
source primers remain provenance; the new order sheet includes the declared new
uses only.
