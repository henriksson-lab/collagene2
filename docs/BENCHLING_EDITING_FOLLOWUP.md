## Recommendations grounded in existing implementation

The useful unresolved question is how to present **biological frame continuity**, not whether we need another translation engine. [Current translation semantics](TRANSLATION.md) already join biological CDS parts before applying one phase offset, preserve strand/origin order, and reject unsupported exceptions. [Selected translation and linked proteins](TRANSLATION_REFERENCE.md) retain exact source events and explicit code/initiation policy.

`assembly_junctions_view.rs` already offers six local window frames and feature-derived CDS review with `codon_start`, genetic code, strand and `needs_review`. Keep its distinction between a window-relative frame and a declared CDS frame visible. A plausible peptide across a junction does not establish a functional fusion. The reviewed public sources supply no additional fusion-correction algorithm or interaction contract to adopt.

For primer reuse, retain our explicit selected binding geometry and exact oligo/source identity. Pair unlink, template detach and display hiding should remain distinct if exposed together. A change to reused sequence or binding must require fresh reconstruction through existing validation; the public descriptions do not justify silently updating saved designs.

For grouped CDS editing, use our existing compound-location preview and review flags rather than reproducing a documented inability to edit regions. If multiple-region creation becomes useful, make biological order, strand, phase and resulting peptide explicit before Apply. This is a product recommendation, not a demonstrated missing capability or a new implementation prerequisite.

## Remaining public-evidence limits

The [DNA/RNA overview](https://help.benchling.com/hc/en-us/articles/39110680274189-DNA-and-RNA-sequence-overview), updated 30 September 2025, describes insertion confirmation, drag deletion and annotation-preserving paste. It distinguishes linear axis relabeling from circular reindexing, where a chosen base receives a specified coordinate. It does not specify Shift/arrow anchor behavior across the origin, full-circle versus empty selection gestures, or compound-feature replacement rules. Existing exact range/location and history policies should govern these cases; no new Benchling-specific gesture is inferred.

The older [Protein Analysis teaching module](https://help.benchling.com/hc/en-us/articles/9684194939533-Protein-Analysis), updated 13 October 2022, demonstrates changing an amino acid through a codon action. It does not specify synonymous-codon choice, compound CDS editing, primer regeneration or physical fusion verification. No current dedicated fusion-reading-frame repair workflow was established by this search. That is an evidence limit, not a claim that Benchling lacks one.
