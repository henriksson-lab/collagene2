# Cloning feature gap triage

Source audit: 2026-11-28. Scope: actual restriction-cloning and Sanger-contig functionality. No code, builds, tests, browser or application HTTP checks were performed. Antibody coverage, BAM/NGS and deferred external scientific engines are not on this cloning delivery path.

## F21: digest conditions are a real feature gap

The plan explicitly requires supplier buffer/temperature/star-activity compatibility, richer catalogs and source-strain presets; these are not merely graphical acceptance tasks. See [PROJECT_PLAN.md:781–785](../PROJECT_PLAN.md#L781).

Recommended coherent F21 batch: extend the current digest recipe with explicit pinned formulation selections and declared conditions; assess common documentary buffer/temperature evidence with unknown/conflict preserved; surface all relevant star-activity qualifiers; retain the assessment and sources in saved setups and protocol output. Add independently curated source-strain presets that expand into editable, source-bound generation assumptions. A strain name must not establish measured modification, silently set CpG, or override explicitly retained positional evidence.

This feature can report documented compatibility or unresolved conditions without claiming yield, complete digestion, absence of off-target cleavage or experimental success. Duration-dependent qualifications must survive comparisons: the current SmaI evidence retains the longer-incubation 25 °C qualification alongside its 37 °C chart observation. A percentage from a vendor unit assay is not a predicted fraction of this plasmid cut. [Catalog scientific semantics](../../crates/enzyme-catalog/README.md#L71).

One documentary inconsistency should be fixed when touching these docs: the enzyme-catalog README still calls catalog-backed application selection a future integration step, although the current web digest already implements it. [Stale README passage](../../crates/enzyme-catalog/README.md#L151), [current implementation](../../crates/web/src/restriction/digest.rs#L197). This is documentation debt, not another missing feature.

## F24: contigs exist; complex-layout capability remains limited

The initial read-assembly workflow is implemented across core, worker-facing web UI and native history. It is reference-free, considers both orientations, uses affine boundary overlaps, retains quality/call/gap evidence and duplicate groups, and exposes unresolved branches and layouts. The UI offers overlap inspection, paged canvas/evidence navigation, exact source-call opening, fresh reconstruction for FASTA/GenBank export, atomic retained evidence and historical replay. [Core model](../../crates/core/src/review/contigs/mod.rs#L42), [UI workflow](../CONTIGS_UI.md), [native history owner](../../crates/core/src/review/contigs/history.rs#L1).

| Item | Actual limit and implication | Triage |
| --- | --- | --- |
| Repeat/cycle/complex layouts | Reciprocal unique-best joins do not resolve arbitrary repeat copy counts or circular layouts. Unsupported branches/cycles can become unresolved singletons; incompatible insertion layouts remain unresolved. Suboptimal paths and all assemblies are not exhaustively enumerated. [Selection/ambiguity](../../crates/core/src/review/contigs/mod.rs#L1437), [cycle handling](../../crates/core/src/review/contigs/mod.rs#L1567), [declared model](../CONTIGS.md#L51). | Real capability limit. Prioritize concrete cloning-read failures rather than promising general assembler parity or automatic repeat resolution. |
| Size | At most 32 linear DNA reads, 10,000 calls/read, 100,000 aggregate calls; bounded pair/cumulative work, edges and columns. [Preflight](../../crates/core/src/review/contigs/mod.rs#L169), [option bounds](../../crates/core/src/review/contigs/mod.rs#L140). | Deliberate resource profile. Larger cloning-read batches need an explicit scoped extension, not removal of limits. |
| Consensus disagreements | Eligible conflicting bases/gaps remain unresolved; support is not a calibrated error probability. No reference base fills missing observations. [Consensus semantics](../CONTIGS.md#L69). | Intentional scientific behavior, not a defect requiring invented probabilities or forced consensus. |
| Real caller corpus | Current contig fixtures provide synthetic independent conservation/alignment/quality cases. Even the tiled “Sanger” case generates short sequence and FASTQ scores in-process. The plan still calls for larger real caller corpora. [Fixture declaration](../../crates/core/tests/analysis/reads/contig.rs#L1), [tiled case](../../crates/core/tests/analysis/reads/contig.rs#L409), [independent oracle](../../crates/core/tests/analysis/reads/contig_audit.rs#L1), [plan](../PROJECT_PLAN.md#L767). | Evidence/validation gap, not proof that the implemented feature is absent or incorrect. Obtain licensed multi-read ABIF/SCF cases with independent expected layouts and deliberately ambiguous cases before broad parity claims. |
| Graphical/platform acceptance | Current viewport pages 25 edges and paints at most 160 columns/12 rows, with paging and exact inspection. [UI](../../crates/web/src/reads/contigs.rs#L779). | Existing functionality awaiting user review/performance/platform acceptance. Do not relabel it as missing implementation or restart browser checks under this audit. |

Multiple-alignment engine ports remain explicitly deferred. F24 does not require launching MAFFT/MUSCLE/Clustal or replacing conservative unresolved states with unsupported biological uniqueness claims. The next cloning priorities are the concrete F21 reaction-planning gap, then demonstrated ordinary Sanger-layout failures and a real assembly corpus. Routine acceptance remains separate from new feature development.
