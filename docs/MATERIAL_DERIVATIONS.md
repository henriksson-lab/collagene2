# Target-free native material derivations

`material_derivation` is the single saved-processing path for `ExactPcr`, `CatalogDigest`, intentional `MismatchPcr` and direct `EndRepair`. Each operation binds its exact source event and explicit native recipe without inventing an intended target or adopting a cloning-run assessment. Saved Run and Derived material remain distinct source families. Native replay, not serialized summaries or matching letters, supplies actual tracked strands, chemical groups, nicks and positional modifications.

`SourceOrigin::OriginalReference` is an explicit intact DNA reference hypothesis with unknown source modifications and terminal groups. Imported physical or reference-only evidence cannot enter this branch. `Saved(MaterialOrigin)` retains the actual closed native ancestry. Installation checks that the selected document still has the exact captured revision/event head and returns a new atomic archive; source documents are preserved. Record ownership, source snapshots, native event parents, opaque recipe bytes and replayed product state are independently checked on reload/reuse.

`ExactPcr` retains both full primers and the selected geometry/preview revision. It uses the established exact-PCR source-coverage model and requires a single geometry. `CatalogDigest` pins the embedded catalog, inspection limits and actual fragment index, preserving separate top/bottom lengths and offsets. Cleavage is a declared reaction assumption, not measured completion or methylation permission. Missing or competing supported geometry is not resolved by a desired sequence.

## Intentional mismatch PCR

`MismatchPcr { forward, reverse, options, selection }` retains the complete ordered oligos, separate 5′ tails and annealing domains, mismatch/3′-exact policy, binding/search/materialization bounds and `MismatchPcrSelection { selected_index, expected_preview_revision, geometry }`. `mismatch_pcr_preview_revision` and `preview_mismatch_pcr` bind those settings to the actual source/origin. The preview carries the full native report, source geometry/modification summaries and bounded inherited findings; `reusable()` exposes the same eligibility predicate as installation.

Reusable mismatch PCR requires exactly one reported certain nonoverlapping native geometry and its exact freshly reproduced selection receipt. Two or more reported geometries remain diagnostic; selecting an index never proves isolation. A singleton with incomplete enumeration follows the existing native kernel: actual conditional material may be retained, while `incomplete`, warnings and search evidence remain sticky. No completeness, absence of competitors or isolation is claimed.

The existing mismatch kernel requires intact fully paired strands without nicks. Saved staggered or nicked sources are explicitly unsupported; this workflow does not automatically repair them. A separately requested, scientifically appropriate repair can establish a supported source geometry. Newly amplified strands use the existing ideal-PCR standard-unmodified synthesis model with blunt 5′OH/3′OH termini. Primer-encoded substitutions are projected into annotations; overlapping source translation assertions are invalidated and flagged for review. Source methylation is not copied into new PCR strands.

## Direct end repair

`EndRepair { method }` processes the freshly reconstructed source directly. `repair_preview_revision` and `preview_repair` expose its native strand mappings and explicit additions/removals before installation. The same existing repair kernels implement template-supported filling and 3′ removal. Original 5′ groups, surviving modifications and internal nicks remain; newly synthesized bases are unmodified under the existing standard-dNTP assumption. Blocked/unknown affected 3′ chemistry remains unsupported. No phosphorylation, nick sealing, factory-vector chemistry, host rescue or target success is inferred.

A repaired product can subsequently be selected as Derived material. Repairs that leave unsupported PCR geometry or internal nicks do not make mismatch amplification supported merely because a repair step was requested. End repair cannot request new primer-order collections.

## Receipts and bounds

Native records/capsules retain the complete recipe and inherited incomplete state. Preview objects expose 128 findings of at most 2048 characters, with total/truncation metadata. Preview molecules carry restrictive generic material-derivation context markers even if their geometry marker is removed; reference previews cannot bootstrap material. Readonly `validate_binding` checks documentary correspondence and bounds, not physical authority.

Optional primer collections are atomic presentation attachments containing only the two newly declared exact or mismatch PCR oligos, including full tails. `Receipt.primer_attachment` is checked against a deterministically rebuilt table. It is absent from the scientific `Record`, so selected sharing can omit presentation collections without changing native ancestry. Digest/repair never reorder historical primers.

The existing shared ancestry ledger charges full wrappers and source models before decoding opaque children: aggregate 32 MiB, depth eight and 1000 steps, with 8 MiB native records and existing model/material bounds. Mismatch calls retain the existing bounded native search policy and reject an estimated call above 200 million units; this does not claim a new absolute end-to-end budget for replaying all closed ancestors. Full preview/report serialization is bounded to 32 MiB. All algorithms are native Rust/WASM with no external scientific process.

`material_derivation_actions` fixtures independently specify substitutions/tails and annotation/order receipts, archive replay and downstream PCR; actual EcoRV cleavage followed by explicit3′ shortening and 13/17-strand repair with retained Dam calls, unknown original outer5′ group, cleavage-created inner5′ phosphate and unmodified filled bases; competing versus conditionally capped mismatch searches; source/policy/geometry guards; and a real nick retained through end repair with mismatch PCR still refused. Existing exact-PCR, catalog-digest, mixed-ancestry and target-based assembly fixtures remain current regression coverage. These interfaces do not claim laboratory success or target verification for target-free processing.
