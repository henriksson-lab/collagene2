# Saved-template TOPO inspection through MCP

`inspect_saved_topo` is a read-only inspection tool. It accepts immutable session `inputs` (`BoundInput` IDs), the explicit `template_role`, a complete native run-material `origin` capsule, and its exact session-owned `origin_workspace`. The server attests source, target, product events and run identity against that archive before replaying the origin and new insert PCR. Similar DNA or imported physical-summary metadata cannot replace this ancestry.

The externally tagged task is `Orientations`, `Project`, `Check`, `InspectActions`, or `ProcessActions`, matching the native saved-template inspection API. `Check.target` is an immutable session `DocumentRef`, not an embedded molecule. It is resolved and checked without substituting the projected graph sequence, choosing transfers or changing the desired target. Vector activation, PCR primers, tailing, transfers, selected graph component/seed, processing and acceptance allowances remain explicit declarations.

The response preserves `origin_incomplete` and bounded `origin_findings` excerpts from the actual fresh originating run replay (at most 128 findings and 2,048 characters per finding), with `origin_findings_total` and `origin_findings_truncated` explicitly reporting omissions. MCP adds no further truncation. These are retained separately from the new task's local graph or target outcome. A successful local inspection or graph comparison cannot clear inherited incompleteness. The response contains a source/task-bound context revision, an honest task summary, and an artifact ID for the complete typed native `Inspection` with original source references, origin capsule/workspace and task declaration. Evidence artifacts are bounded to 32 MiB; literal task options are bounded to 2 MiB. No candidate or projected document is saved. A comparison outcome under explicit graph assumptions is not experimental success, isolation, mixture uniqueness or standalone reusable-material authority. Reuse requires the ordinary native typed plan and fresh saved-origin replay.

The SDK fixture uses a real finalized PCR workspace, actual session archive import and run-material preparation, explicit vector-source declarations, and saved-template inspection. It tests refusal of an unrelated archive, stale source revision, wrong template role, omitted workspace and stale/embedded target, while retaining an independently selected mismatching target.
