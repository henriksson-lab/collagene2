# Oligo tables and FASTQ evidence

`collagene_core::oligo_formats` implements explicit source adapters in Rust. CSV syntax uses the standalone MIT/Unlicense [csv 1.4 library](https://docs.rs/csv/1.4.0/csv/), with an independently implemented strict quoting preflight; no cloning application, external parser executable, ordering service or scientific tool is invoked.

## CSV/TSV oligo collections

`inspect_table(text, delimiter, has_header)` reads source columns without inferring biological roles. `import_oligos(text, options)` applies explicit zero-based `ColumnMapping` indexes for name, ordered sequence, annealing domain, 5′ tail, modifications, amount and unit. At least an ordered-sequence or annealing-domain column is required. Distinct roles must use distinct columns; missing mapped cells make a row evidence-only rather than inventing a value.

The quoting profile follows [RFC 4180](https://www.rfc-editor.org/rfc/rfc4180.txt) with explicit comma/tab delimiters, UTF-8, LF/CRLF records, escaped quotes and quoted multiline fields. Unclosed/bare quotes, trailing text after a quoted field, bare CR outside quotes and unsupported controls are rejected. Ragged rows remain inspectable; a mapped field must actually exist in each convertible row. Headerless input uses explicit generated column labels. Duplicate names remain unchanged, with separate table-hash/row-index identifiers.

The imported `OligoTable` retains the exact original table once, its BLAKE3 hash, mapping, headers and every row, including unsupported rows. Each `OligoRecord` also retains its exact source record segment, original fields, literal modifications and quantities, diagnostics and optional usable `Primer`. A table's `validate()` re-derives records from its retained source and mapping; imported JSON cannot claim an unmodified primer inconsistent with those fields. The original source and normalized scientific values remain distinct.

Only plain DNA/IUPAC symbol strings under the selected mapping can supply a `Primer`. No slash/bracket/asterisk modification notation is stripped. Any explicit nonempty modification field makes the row evidence-only, including a modification whose chemical meaning is familiar but not modeled here. Valid IUPAC letters retain their alphabet meaning; modification shorthand cannot be inferred from those same letters. Degenerate oligos remain visibly ambiguous and do not become concrete exact-PCR primers. RNA and modified chemistry need separate models.

When ordered sequence, domain and tail are supplied, they must agree as `tail + domain`. If only an ordered sequence is mapped, the mapped tail must be its proper prefix; absent domain/tail roles cause the whole ordered sequence to be used as the annealing domain with an explicit diagnostic. No strand orientation or bound template is inferred from a name. Oligos are limited to the initial 200 ordered-base profile.

Supported literal amount units are mol/mmol/umol/µmol/μmol/nmol/pmol, normalized to mol. Supported concentration units are M/mM/uM/µM/μM/nM/pM, normalized to mol/litre. Values must be finite and positive. Unknown/absent units, combined free text and invalid quantities remain literal evidence with diagnostics; units are never inferred from a header or silently case-folded. These fields describe an imported oligo/order sheet, not inventory, stock management or procurement automation.

`selected_molecules(indices)` converts only explicitly selected computable rows. The actual ordered DNA becomes a linear **ss-DNA reference**; its `primer_bind` domain excludes the tail, and qualifiers retain separate ordered/domain/tail values for reuse. Declared single-stranded documents cannot silently become intact duplex cloning substrates. Each document retains its own raw row and table hash, while the complete table belongs once in the workspace's collection/attachment. Saving a single row does not preserve every other row; the import warning makes that limit explicit. Empty selection can retain a collection without creating a fabricated carrier sequence.

`export_oligos(table, delimiter, mode)` creates a quoted order sheet with original fields retained as JSON. `SpreadsheetSafe` apostrophe-prefixes formula-like cells and reports that intentional display-value change. `MachineData` preserves literal values and reports formula-like cells; CSV quoting alone does not prevent spreadsheet evaluation. Original downloads and collection JSON retain literal evidence. No safety marker is silently removed on re-import.

The Leptos `OligoImport` component provides source/delimiter/header controls, explicit role selectors, 100-row pages, computable-row selection, evidence-only status, original/JSON downloads and spreadsheet-safe order sheets. Its callback returns the whole table and selected indexes for an atomic parent workspace transaction. A retained table can be reopened without copying its original source onto every DNA document.

## FASTQ with an explicit quality encoding

`import_fastq(bytes, QualityEncoding::Phred33 | Phred64)` requires an encoding choice. The [NCBI FASTQ format guide](https://www.ncbi.nlm.nih.gov/sra/docs/submitformats/#fastq-files) documents identifiers/descriptions, DNA calls, the `+` delimiter, equal-length qualities and the two common ASCII offsets. This adapter accepts printable ASCII Phred values under the selected offset, not Solexa log odds, decimal quality lists or automatically guessed encodings. Character ranges that fit both encodings remain ambiguous until the caller chooses; no quality is invented for FASTA/plain DNA.

Wrapped sequence/quality lines, LF/CRLF, descriptions and duplicate read IDs are supported. `@` and `+` inside quality strings are scores, not new delimiters. A nonempty `+` identifier must match the complete source header or its read ID. Whitespace/gaps/RNA in calls, invalid scores, mismatched lengths, truncated records and blank inter-record lines reject the import. Read pairing, instrument/platform fields and calibrated error probabilities are not inferred.

Each resulting document retains its exact original **record** bytes/hash, whole-input hash, record index, full header, supplied score bytes, explicit encoding and orientation. `quality_evidence` validates those fields against the original record. It returns current-oriented `called_sequence` and `qualities`, the original full call length, and half-open `retained_start/end` in the **original full forward record**. For current call `i`, the original call is `retained_start + i` when forward, or `retained_end − 1 − i` when reversed. These are base-call coordinates, not chromatogram sample coordinates.

Generic sequence edits and unsupported coordinate transformations do not silently realign scores. `export_fastq` refuses stale/currently unsupported quality mappings, while `original_fastq_bytes` still returns the original attachment. The generic reverse-complement adapter calls `project_fastq_reverse_complement`, which reverses scores even when DNA is palindromic. `trim_fastq(source, start, end)` explicitly retains the corresponding source-quality slice and coordinate provenance. Reverse-trim/reverse chains preserve original call coordinates rather than guessing from repeated sequence. Current export uses canonical uppercase/four-line framing and refuses a quality-encoding conversion that cannot represent a source value losslessly. Rich annotations remain outside FASTQ and are reported as export loss.

Limits: 8 MiB source oligo tables, 10,000 rows, 64 columns and 8,192 bytes/cell; collections and derived batches must fit 32 MiB serialized output. FASTQ accepts at most 32 MiB source, 10,000 records and ten million total called bases, with per-document/batch native payload bounds including retained evidence. This is an initial small-data profile; streaming indexed NGS-scale storage, compressed containers and richer quality models remain separate work.

## Validation

`cargo test -p collagene-core --test formats sequences::oligo_formats:: --locked` covers independently authored CSV/TSV quotes/BOM/multiline cells, exact CRLF record boundaries, column conflicts/ragged rows, duplicate names, explicit modifications/units, formula export policy, native single-stranded primer documents and tampered collection rejection. FASTQ tests cover explicit offsets/conversion failures, wrapped framing, raw-source round trips, stale edits, corrupt evidence, palindromic reversal, and asymmetric trimming/reversal with manually specified scores and original coordinates. Independent short-cell and 4,096-sequence/quality framing matrices exercise delimiters and quality-marker ambiguity without another application's output as an oracle.

JSON uses `serde_json` with `float_roundtrip` enabled. Source-derived normalized SI quantities are checked exactly on collection reload; parsing a printed value must preserve its binary `f64` value. A regression covers 25/50 nmol and independent amount/concentration expectations, validates after JSON reopening, and checks exact original-source and serialized-byte preservation. Raw amount/unit fields remain the primary source evidence.
