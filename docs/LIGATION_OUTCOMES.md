# Intended ligation and bounded alternative paths

`ligation_outcomes` analyzes freshly reconstructed actual `TrackedDuplex` operands. The caller supplies unique source keys and an explicit intended order/orientation. No target sequence chooses a path. No probabilities, concentrations, efficiencies, yields or kinetic predictions are computed.

The intended path is executed first through the existing `modified_duplex::ligate` model. If compatible and representable within the declared bounds, it is always retained separately as `Report.intended`, even when alternatives exist or enumeration is capped. An incompatible intended path is an explicit native error, never silently replaced by an alternative. Alternative existence does not invalidate the intended path or imply that it has been isolated experimentally.

Each returned `Product` contains its machine-readable keyed order/orientations, actual sequence/topology, full duplex including free ends/nicks, and a positional-modification summary with state revision. Ordinary stored-strand reversal is the existing native tracked reversal: unequal source strands are swapped as actual material, not reconstructed by reverse-complementing an arbitrary top reference. No missing DNA, phosphate or end repair is invented.

The scope contains **one copy of each declared fragment**. Circular enumeration fixes the first intended fragment and its intended orientation as the coordinate anchor, eliminating equivalent rotations/global reversal of that anchor. Linear paths retain all declared orders/orientations; some can be equivalent whole-product coordinate views or identical DNA with different source paths. Source identity/path is not deduplicated merely because letters match. Vector-only products, self-ligation without all declared fragments, multimers, other copy numbers and partial assemblies remain outside this bounded scope. Two retained paths therefore never means only two experimental mixture products.

`enumeration_complete` says the declared path space was traversed without a resource stop. `exhaustive_within_scope` additionally requires no unresolved chemical/model states. Native unknown/unsupported junction evidence remains in bounded `unresolved_examples` and counts rather than being called proven incompatibility. Compatible returned alternatives remain individually extractable. Resource limits identify incomplete searches; an alternative computed at the report-byte boundary can be counted as withheld rather than silently omitted. No withheld result upgrades scope completeness.

Bounds retain intended paths for up to 32 operands and enumerate alternatives for at most 8 (or the explicit smaller `max_enumeration_fragments` request bound). Above that enumeration limit the native intended path is still evaluated and retained, with `EnumerationFragments`, one checked path and incomplete/unattempted alternative-search status. Bounds also include 32 MiB aggregate serialized input material, two million total input-strand bases, explicit path/product/report/material-base limits, and a charged native material-base work budget (default 20 million, maximum 100 million units). Four units per input base reserve validation/reversal work; six per trial base reserve native material copying/composition. These units bound repeated native calls and their base visits, not exact processor instructions or wall time. Full actual intended-output storage must fit before a report is returned. The same budget applies to intended and alternative paths; nested analyses do not occur here.

`revision(operands,request)` binds the literal request/bounds and every keyed actual material-state revision. `Report::validate_binding` performs bounded documentary/context and one-copy strand-accounting checks. It does not restore material from serialized reports. The verifier uses private `analyze_fresh(...).into_parts()` to receive the actual intended `TrackedDuplex` from the single native execution alongside its report; the fresh type has no public constructor or serialization. Other consumers must rerun the selected keyed path against their own exact captured native sources before downstream physical use. Stored scientific/material engine labels keep historical documentary context reproducible without granting a current verdict.

Focused fixtures independently specify both insert-orientation sequences for TA tails, blunt ends and identical EcoRI ends; distinct EcoRI/HindIII ends admit only the intended anchored circle. Further fixtures retain literal unequal 13/17 strands under reversal, preserve the intended product under search/product/work caps, and keep uncertain alternative chemistry unresolved. The current native junction model already rejects all-hydroxyl blunt ends even when nicks are permitted: at least one new phosphodiester bond is required at each joined boundary. This module does not change that scientific rule.

New workflow compilers now use `LigateWithOutcomes` for up to32 declared operands; larger supported ligations retain the legacy ordered-only operation. Manually retained old `Ligate` plans keep their semantics. The verifier carries the actual intended native material forward and stores full outcome evidence in the existing physical-processing run companion. That complete evidence is hashed into the intended product's native receipt, and historical loading checks its exact source/product correspondence. HTML protocols contain every retained path plus extractable FASTA and typed JSON. Alternative DNA never rescues an incorrect independently declared intended target.

Alternative-enumeration limits retain the intended product. A distinct failure to represent the complete bounded report/history (including the verifier's global32MiB processing-evidence bound) is an explicit resource refusal; full alternatives are not silently omitted and explicit options are not changed to conceal that failure. Core fixtures cover real run capture, reload/replay, intended-vs-alternative target separation, capped-search capture, large ordered fallback and altered historical evidence refusal. Frontend delivery/validation remains separate from the native source contract.
