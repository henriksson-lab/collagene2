# Legacy migration fixtures

`serializer-shaped-project.collagene` is independently authored synthetic XML matching the attributes/containers written by original Collagene commit `33f682a7156b875be730e18fa019ce310c9e54f6`. It was not generated by running the old application and is not a real laboratory project. It tests duplicate document names, source notes, oriented/origin-crossing annotations, primers, aligned gap columns and unmapped physical evidence.

No biological `.collagene`, `.seqfile`, XDNA, XDGN or XPRT sample documents were present in that original repository revision. Native producer interoperability remains unverified until real files are available. Unit tests independently specify XDNA bytes from the documented field layout, rather than treating another parser's output as an oracle. Original application source is audited for serialization facts only; no application/scientific code is borrowed into Collagene 2.
