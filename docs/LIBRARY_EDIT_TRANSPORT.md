# Source-library contribution edits: transport and native identity

The existing selected-construct contract carries `OriginalRegions{junction_edits,substitutions,edits}` with all three vectors required. Edits use original oriented-contribution coordinates and exact expected literals, bound to the construct's stable source roles. Empty vectors explicitly declare no such changes. Existing-target declarations remain separate retained references.

The target is built from original source regions, trims/inserts and literals before preparing DNA. A changed target does not alter PCR settings, select a reaction product or make an unchanged preparation satisfy the mutation. Native batch rows retain independent draft/error/evaluated states and fresh scientific status. Editing one construct never changes all rows sharing its source choice.

The existing `DesignEditedOverlapPrimers` worker job takes `inputs`, native `request`, and required-nullable `workspace`. Pure original references use `null`; saved Run/Derived origins use an exact owning native archive. The existing result remains `EditedOverlapPrimersDesigned`. The request uses the compound 128 MiB admission lane; native origin/model/search/report limits still apply independently, and the result stays within the ordinary report limit. The worker's current schema is advanced once for this contract; no prior reader is retained.

The existing MCP `design_edited_overlap_primers` tool accepts the same literal planner request except that the intent contains one compact per-input binding roster (`input_id` plus exact native selection), plus one required-nullable `origin_workspace`. All Run/Derived selections are jointly hydrated from that exact immutable session workspace under the shared native origin budget, without chemistry replay during hydration. Exact selected source snapshots are checked before cloning. The native planner then performs real saved-material reconstruction and physical PCR/OE/whole-recipe checks. Client-supplied closed origin graphs and per-role workspace fallback forms are not accepted. No new tool is introduced (registry count remains 192).

The returned proposal is advisory: full native evidence and exact small source/workspace selections are retained in the immutable JSON artifact; ordered oligos distinguish exact PCR and left/right/outer OE stages. `FromRun` and `FromDerived` preserve their actual native origin. Neither intended target, candidate nor scientific material is installed by planning. Applying preparations and capturing a batch remain explicit, source-pinned actions with real persistence acknowledgements.

The planner supports the existing overlap model, not arbitrary library-wide Golden Gate/ligation oligo synthesis. Missing, malformed, stale, incompatible or uncertain proposals retain native errors/findings rather than becoming physical acceptance.
