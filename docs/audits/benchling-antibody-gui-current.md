# Benchling antibody GUI and workflow evidence

Research date: 2026-11-28. **Antibody support remains in scope**, following the user's clarification that capabilities present in Benchling/Geneious belong in the product comparison. This report investigates Benchling specifically; it does not establish Geneious parity. The completed [cloning-gap triage](cloning-gap-triage-current.md) remains useful for F21/F24 facts, but its statement excluding antibody coverage from the delivery path is superseded by that clarification. Root plan/scope documents are not edited here.

Evidence labels below distinguish **observed screenshot**, **documented text**, and **proposed acceptance**. Six existing official external screenshots were downloaded to `/tmp` and visually inspected; no Collagene browser, screenshot, CDP, application HTTP, build or test was run. Public images are linked, not copied into repository assets. Older marketing images show historical appearance rather than a promise about every current deployment.

## Documented product coverage

[Benchling's antibody help](https://help.benchling.com/hc/en-us/articles/9684246077325-Annotate-antibody-specific-information-on-protein-sequences), updated July 13, 2026, documents automatic variable-domain annotation on proteins and alignments:

| Dimension | Documented coverage |
| --- | --- |
| Numbering | Kabat, Chothia, IMGT |
| CDR/framework definitions | Kabat, Chothia, IMGT, North; separately configurable from numbering |
| Antibody chains | Heavy, kappa, lambda |
| TCR chains | Alpha, beta, delta, gamma; human/mouse and IMGT only |
| Organisms | Human, mouse, rat, rabbit, rhesus, pig, alpaca |
| Input bound | Up to 2,000 residues |
| Presentation | Numbering, CDR/framework and liability tracks; zoom may hide individual numbering labels |

These are documented product claims, not an independently measured detection benchmark. No negative-result or ambiguous-domain screenshot was located. Do not infer a species picker, confidence calibration, automatic disambiguation, multi-domain completeness or behavior on arbitrary antibody formats from the organism list.

## Documented alignment, editing, selection and export workflow

The [current alignment guide](https://help.benchling.com/hc/en-us/articles/39922093033869-How-to-create-alignments) documents protein alignment creation through Global Create or a sequence's right-hand Alignments toolbar. Users add existing proteins, choose/remove a template, create an alignment, and reopen saved alignments from a source. Protein alignments are read-only; Realign incorporates source edits or changed rows. It documents both global gear settings and per-row dropdown visibility, plus FASTA/PNG/PDF export from an upper-right export dropdown. Its Clustal Omega implementation is competitor behavior, not a requirement to resume the user's deferred external engines.

That guide lists liability motifs `N-X-[ST]` (X≠P), `NG|NS|NT|NN`, CDR-local Asn, `DG|DS|DT|DD|DH`, M and W. The separate antibody article's deamidation prose conflicts internally with this motif list; do not silently treat that inconsistent prose as a scientific rule oracle. Existing independently sourced Collagene motif semantics must remain authoritative for its own implementation.

The reviewed sources do not establish exact antibody-region click selection, keyboard editing behavior on an individual sequence, export inclusion of every displayed annotation, clipboard semantics, or negative/ambiguous-domain states. Those remain explicit design/acceptance decisions, not observed Benchling parity.

## Actionable acceptance mapping to current Collagene code

This is a source comparison, not a visual acceptance result. Existing code should be reused and improved directly; no second antibody representation or compatibility layer is needed.

| Proposed acceptance | Current implementation evidence and concrete implication |
| --- | --- |
| One coherent display menu for protein tracks, with independent visibility and nested settings | Current `AntibodyPanel` lives in the Biology inspector alongside a separate liability panel. Numbering/region settings and selected-candidate overlay already exist. [App integration](../../crates/web/src/app/mod.rs#L2228), [antibody controls](../../crates/web/src/biology/antibody/antibody_view.rs#L223). Adapt these owners into the existing menu system; avoid expanding a permanent toolbar of analysis buttons. |
| Separate source-coordinate axis, numbering track and region bands; legible zoom behavior | Current overlay paints region backgrounds and sparse number labels, with unresolved marks. [Drawing owner](../../crates/web/src/biology/antibody/antibody_overlay_draw.rs#L5), [sequence integration](../../crates/web/src/viewer/sequence/sequence_view.rs#L1554). Review spacing and track separation against the inspected images; retain exact source indices and insertion labels. Missing low-zoom labels should have an explanation rather than suggest detection failed. |
| Numbering and CDR definition remain independent | Both individual and alignment panels already expose three numbering schemes and four region definitions, including North. [Protein controls](../../crates/web/src/biology/antibody/antibody_view.rs#L225), [alignment controls](../../crates/web/src/biology/antibody/alignment_antibody_view.rs#L203). This is implemented functionality, not another missing North feature. |
| Each supported species/chain is explicitly disclosed; unsupported inputs remain honest | Current reference model is human heavy/kappa/lambda only. [Locus owner](../../crates/antibody-numbering/src/v_mapping.rs#L9), [UI scope](../../crates/web/src/biology/antibody/antibody_view.rs#L224). Benchling's broader species/TCR list is a real coverage gap. Add only independently sourced, licensed, validated profiles; do not relabel human nearest-reference evidence as another species. |
| Liability dots have hover/keyboard equivalents and a visible selected type | Current liability panel has complete counts, certain/possible hits, filtering, exact match selection, review-required annotation and JSON export. [Liability view](../../crates/web/src/biology/protein_liability_view.rs#L274). A sequence-level dots/hover track integrated with antibody regions is a concrete presentation gap; preserve accessible list inspection and “candidate pattern” wording. |
| Alignment tracks can be compared across rows without losing source mappings | Current analysis focuses one row and excludes alignment gaps from numbering. [Focused-row panel](../../crates/web/src/biology/antibody/alignment_antibody_view.rs#L201), [canvas](../../crates/web/src/viewer/alignment/alignment_view/mod.rs#L533). Benchling's screenshot shows simultaneous tracks on multiple rows. Broader row display needs source-bound per-row results, not labels copied from the template or a new alignment engine. |
| Selected region/residue can be inspected without editing raw numbering labels | Current table selects exact source residues; overlay diagnostics retain unresolved assignments. [Selection/diagnostics](../../crates/web/src/biology/antibody/antibody_view.rs#L245). Keep editing on the sequence owner; source edits invalidate pending/current scientific captures. Region selection UX is a proposed acceptance requirement, not observed Benchling behavior. |
| Clear no-result and ambiguity states | Current UI reports retained-candidate counts, truncation, candidate choice and unresolved mappings. [Result status](../../crates/web/src/biology/antibody/antibody_view.rs#L213), [candidate controls](../../crates/web/src/biology/antibody/antibody_view.rs#L240). Distinguish not run, running, no qualifying candidate, unsupported scope, unresolved/ambiguous and resource-limited results. Zero retained candidates can also mean explicitly requested counts-only; never conflate it with no domain. Benchling negative-state appearance is unverified. |
| Export the chosen view and retain full evidence separately | Individual antibody and liability JSON exports exist. [Antibody export](../../crates/web/src/biology/antibody/antibody_view.rs#L253), [liability export](../../crates/web/src/biology/protein_liability_view.rs#L282). Verify display-export integration includes requested tracks and records scheme/definition/candidate/source identity; do not claim existing generic SVG/PNG export already includes them without source inspection and later user acceptance. |

Do not confuse Benchling's Molecular Biology feature with its separate PipeBio or newer Biologics product workflows. For example, [Benchling's liability article](https://www.benchling.com/blog/antibody-liabilities) explicitly describes PipeBio scaffolds, germline reconstruction and additional validations. Those claims do not prove that the compact Molecular Biology display menu offers every such operation. This audit therefore restores antibody scope while bounding the comparison to directly documented and observed behavior.
