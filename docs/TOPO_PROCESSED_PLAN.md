# TOPO material in deterministic cloning plans

`Operation::TopoActions` is the current source-bound physical bridge operation.
It contains exact `TopoSource` bindings and the canonical `topo_actions::Request`
with preparation steps, source-seeded contour selection and explicit options.
Original transfers and all declared processing are one chronological transcript.
There is no separate processed-TOPO operation or phase report representation.

Fresh verification reconstructs the exact source recipe and native graph origins,
executes its steps once, and proves the selected actual contour. Full typed
`TopoActions` evidence remains in `physical_processing_reports`, including
withheld contours, other components, blocked/unknown steps, free flaps and
remaining activations. The independently declared target compares with the actual
result; it supplies no source calls, path choice or repair.

A faithfully bridged result supplies private tracked material to later native
operations. Digestion and other supported transformations consume actual strands,
ends, nicks and the retained Unknown modification model, rather than importing a
portable molecule as chemical stock. The standalone output document is restricted
reference data; ordinary archive/import does not make its summary authoritative.
Saved Run/Derived replay still requires the exact native source/product events and
fresh current execution.

A complete selected contour does not establish isolation or exhaustive reaction
mixture behavior. Unapplied/unsupported operations and inherited incomplete source
history remain explicit. A permissive contour option or target match cannot
silently upgrade them. Withheld material remains diagnostic, and a separately
wrong independent target remains Invalid.

[Native graph capture](TOPO_GRAPH_HISTORY.md) now retains an actual post-cleavage
or nick-sealed prefix as an entire reusable graph. A resumed graph can use its
remaining original activation or further explicit processing. It adds no second
PCR, reconstructs no source from target DNA, and preserves excised components.

The current worker/candidate/native-plan/scientific contracts advance together for
the canonical transcript. Old internal phase requests, record kinds and plan
encodings are not decoded or converted. External sequence-format import remains
a separate capability and cannot restore physical authority.
