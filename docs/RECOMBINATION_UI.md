# Recombination workflow

Open **More tools → Recombination** on desktop. The active document is the independent target. Choose two source documents and explicitly enable the versioned manufacturer-context profile, then choose BP or LR and reconstruct. The [BP example](../fixtures/recombination-bp-demo.md) includes inputs, an independently calculated target and the reciprocal byproduct in one GenBank file.

The current profile contains eight full reference contexts from the cited attB primer strings, pDONR221, pDEST14 and pENTR-D-TOPO. Its edition, content revision and resource limits are visible under **Profile and search limits**. Other contexts and MultiSite remain outside this profile; a missing match does not establish biochemical inactivity. The core and MCP support explicit custom profile snapshots; the current panel exposes the pinned manufacturer edition.

Each candidate retains every reciprocal component. Page through components and select one explicitly. **Check independent target** reconstructs the sources afresh and reports matches without choosing a component. Circular rotations are equivalent; this panel preserves orientation and does not use reverse-complement equivalence. Possible IUPAC sites, ambiguous DNA, unsupported geometry and incomplete searches remain visible. Target matching does not repair DNA or establish experimental success.

**Review selected component in Plan** creates a typed reference-exchange candidate with the complete source/profile/options binding. Verify it against the separate active target. A matching result is **Incomplete** because physical chemistry, biological repair, host selection and efficiency are not established. The plan can retain products through the existing explicit incomplete-run recording workflow and export HTML/PDF protocols with its limitations. Selecting a byproduct is allowed; the selected component must match the independently specified target. A reference-only descendant cannot acquire chemical authority through PCR, ligation, annealing or another operation.

Source identity includes the exact document, head event and molecular revision. Source order, target identity, workspace epoch, profile, reaction and limits invalidate retained UI results. Borrowed source and target guards run before document copies. Jobs run through versioned binary Rust workers; cancellation terminates an isolated job. The panel retains preferred exact source events through Plan verification and recording, including equal-content documents.

The evidence download contains the reference report, reciprocal products, annotation projections, reviewed co-sourced overlaps and retained unmapped annotation evidence. It is descriptive data. Imported evidence must pass fresh source-based reconstruction before releasing a selected product. Native history retains the causal inputs; GenBank/EMBL preserve only bounded, unverified producer claims and a restrictive reference-only marker. Plain sequence formats cannot preserve the full model or source graph.

See the [scientific model](../crates/recombination/README.md), [core adapter](RECOMBINATION_ADAPTER.md), and [MCP interface](RECOMBINATION_MCP.md) for exact rules, source evidence and boundaries.
