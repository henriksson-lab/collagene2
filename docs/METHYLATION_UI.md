# Methylation review in the web interface

Open **Methylation**, or choose **Review methylation assumptions** from **Digest**. The active DNA document is the source. Select enzymes from the versioned starter profiles and explicitly declare Dam, Dcm and CpG assumptions: **Unknown** (the default), **Assume unmodified**, **Assume fully modified**, or **Hemi / mixed (unsupported model)**. Sequence content, organism names and imported annotations do not establish a molecule's actual modification state.

**Assess methylation** runs the embedded Rust context scanner in a background worker. The result binds the exact source document, history event, molecule revision, complete options, profile revision and workspace epoch. Changing any bound source or assumption invalidates it. **Cancel methylation assessment**, source replacement and leaving the panel terminate pending work. Identical molecule content in a different document does not inherit a pending assessment.

The restriction planning review separates **Permitted under profile**, **Blocked under assumptions**, **Impaired under assumptions**, and **Unknown / unresolved** outcomes. A permitted result concerns the modeled methylation profile only. It does not establish a complete digest, reaction conditions, yields, star activity, accessibility, modification inheritance or experimental success. A complete scan is not an observation of methylation. Legacy cleavage-based digests and gels retain their own assumptions; this review does not change their verification status. The separate [checked Plan workflow](CHECKED_RESTRICTION_UI.md) records source assumptions and reconstructs inherited positional state.

The profile disclosure retains exact supplier identities, sources, notes and Dam/Dcm/CpG sensitivity categories. Some-overlap rules remain unresolved when the profile does not identify affected combinations. Generic enzyme identities are not replaced with a supplier's newer formulation. Conflicting or missing formulation evidence stays explicit. Dam models N6-adenine at GATC, Dcm models 5-methylcytosine at CCWGG, and CpG models 5-methylcytosine; other modification systems are outside this assessment.

Site filters support review by enzyme and outcome. Sites are paged in groups of 25. Each selected site shows recognition certainty and orientation, original sequence coordinates, separately optional top/bottom cut boundaries, the three category-specific reasons, exact contextual motif positions and modeled target bases on both strands. Circular contexts retain their wrapped original indices. Ambiguous recognition or context does not become a certain site. **Open recognition start** and **Open target base** navigate the exact bound source event with the same document/event/epoch safeguards used by read assembly.

Comparison and retained-site limits are explicit. Incomplete reports retain their limits and cannot establish that additional sites are absent. Viewing, filtering and paging retained evidence do not rerun scientific analysis. **Expand methylation** provides a larger responsive review surface.

**Download methylation report** exports bounded JSON containing the full core report and the exact source document/event binding. The JSON is a producer assessment under stated assumptions, not portable current verification. No report attachment, modified-base metadata, new molecule, physical digest product or history event is created. Source history remains unchanged. **Review cleavage assumptions** returns to the separate digest workflow.

Developer coverage is in `scripts/methylation_browser_qa.py`, using synthetic sequences against the actual WASM worker. It includes explicit source states, supported blocking and unresolved formulation cases, independent IUPAC/orientation/circular-coordinate checks, exact source identity and options cancellation, target-base navigation, resource limits, bounded site inspection, mobile layout and unchanged source history.
