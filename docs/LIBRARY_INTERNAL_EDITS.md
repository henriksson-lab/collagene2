# Internal edits for individual library constructs

A source-library construct retains its own substitutions, insertions, deletions and replacements. Positions refer to the original contribution in construct orientation; expected source letters remain part of each declaration. Switching constructs restores that construct's edits and preparation settings. Creating a new construct starts with no internal changes, even when it selects the same sources.

Internal changes define intended DNA. They do not change preparation settings or establish a physical product. Batch evaluation sends those exact declarations to the existing native independent-intent builder before compiling the selected preparation. A preparation that does not implement a declaration remains a diagnostic mismatch.

The existing internal-edit controls apply to the selected construct. A changed source or selector must be explicitly captured as a choice before adding declarations. Capturing a replacement choice clears the affected contribution's existing literals; equal sequence content is not sufficient to transfer them. Reordering unchanged source bins preserves their stable role ownership. Removing a bin retains discarded literals in the existing reviewed recovery record, with explicit retained/recovered counts.

## Explicit primer proposals

After reviewing the intended construct, **Propose primers for this construct** uses the existing whole-construct edited-overlap planner. Unchanged contributions receive ordinary PCR proposals; edited contributions receive the actual two source PCRs, reciprocal overlap extension and outer PCR. Applying a reviewed proposal changes only the selected construct's permitted PCR preparations and requested uniform overlaps. Other constructs and upstream source heads remain unchanged.

The proposal retains exact source events, selected choices, internal declarations, options and the frozen independent target. A changed source, construct, declaration, workspace scope or proposal refuses application. Saved Run and Derived inputs retain their native origins and are replayed through the corresponding existing preparation; their visible molecule is not substituted for physical state.

The planner still requires reference-range contributions, two to twelve overlap contributions, supported PCR preparation choices, uniform overlap bounds and compatible explicit tails. Unsupported actual-strand selectors and non-PCR preparation choices remain explicit refusals. A proposal's native findings and verification status are shown as diagnostics; applying oligos does not accept a physical product or predict experimental success.

## Persistence and checks

The sole current draft format (v17) stores required bounded `substitutions` and `edits` vectors in every construct's saved settings. The active working declaration retains its existing top-level vectors. Source models are not duplicated to validate saved literal bounds. Raw declaration keys include both vectors, so even stale expected text invalidates an earlier batch result. Native workspace archives retain the complete current draft and recovery state. The sole current history record (v2/schema2) stores the retained and recovered internal-edit counts explicitly.

Focused native web fixtures cover independent literal targets for two constructs sharing sources; save/reopen/switch; bin reorder and removal recovery; replacement-choice invalidation; required persisted fields; row-local native batch projection; and explicit primer application followed by native archive restart without changing another construct's overrides.
